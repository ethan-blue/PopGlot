# PopGlot 全面评审与 AI 执行包

评审日期：2026-09-05。代码基线：`feb77d5`，项目声明版本：0.1.3。

本次交付是评审和整改执行说明，未修改产品实现。请不要把本文档的新增，误认为其中的问题已经修复。

## 使用方式

1. 项目负责人先读 [完整评审](REVIEW.md)，了解事实、风险、产品取舍和优先级。
2. 把整个项目（包括这个目录）提供给负责实现的 AI。
3. 将下方提示词完整粘贴给它。详细设计、每项任务的文件入口、测试输入和验收条件分别在 [执行规则](AI-RULES.md) 和 [任务书](TASKS.md)。不要只转发评审摘要。
4. 下一轮只需粘贴“续做提示词”。由执行记录决定进度，不靠 AI 回忆。
5. 实现结束后，另开一次审查上下文，使用“独立验收提示词”。不要只让实现者自称完成。


## 文档性质

- REVIEW.md：本次观察，区分直接复现、静态证据、待验证风险和产品建议。
- AI-RULES.md：后续整改的明确目标设计，不代表当前产品已经这样实现。
- TASKS.md：任务粒度的执行契约，包括依赖与验收条件。
- EXECUTION-LOG.md：由实现 AI 新建；本轮评审不预先把任何整改任务标记完成。

这些提示词用于你反复交给其他 AI 执行，不会自行启动后台循环，也不会替你自动部署。
