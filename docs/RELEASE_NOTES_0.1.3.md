# PopGlot 0.1.3 发布说明

0.1.2 的体验收口与安全加固版。本版本完成 09-03 全量 UI 审查的两批修复，
并修复 Rust Core 三处边界问题。用户可见的改进集中在：复制不再卡界面、
界面字号与控件全面统一、朗读快捷键不再与重试冲突。

## 修复

- **复制时界面冻结**：划词复制、QuickSearch 复制、Markdown 代码块复制三处全部移入
  STA 工作线程并加硬超时；剪贴板被 Office、RDP 或剪贴板增强工具占用时界面不再冻结，
  失败时明确提示"剪贴板被占用，未复制"。
- **伪装内网端点不再放行**：本地基础设施判定改为精确 RFC1918/loopback 解析，
  `10.evil.com`、`172.32.1.1` 等公网伪装域名/IP 不再被允许 http 明文连接。
- **取消偶发失效**：修复 FFI 请求注册的票据 ID 冲突，重复 ID 不再导致在途请求无法取消。
- **长流式输出被误断**：SSE 单事件上限放宽到 256 KiB（对齐架构文档契约），
  长文本增量与密集截图转写不再中断整条流；流式上游错误消息增加截断保护。
- **旧配置兼容**：兼容 ≤0.1.2 的旧 ASCII 括号模板名「Ollama (本地)」。

## 变更

- 字号归一刻度：壳标题 20、译文 14.5、metadata 11；徽章圆角 6、IconButton ≥32、
  侧栏宽度 168 等控件尺寸统一；chevron 几何收敛为共享资源并清理死资源。
- QuickSearch 朗读快捷键由 `Ctrl+R` 改为 `Ctrl+P`，`Ctrl+R` 全局统一为"重试"。
- 深浅主题文本与关键边框持续通过 WCAG 2.1 AA 对比度审计。

## 发布与兼容性

- Windows x64 self-contained 便携包，无需预装 .NET。
- 配置 Schema 不变，可直接覆盖旧版程序文件，用户配置无需迁移。

## 验证

- Windows 逻辑测试：121 项。
- Rust Workspace 测试：150 项（cargo test --workspace --locked --release，clippy -D warnings 与 fmt 全绿）。
