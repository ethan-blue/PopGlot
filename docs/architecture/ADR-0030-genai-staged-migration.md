# ADR 0030: 分阶段迁移到 genai 协议适配层

- 状态：已接受，第一阶段已落地
- 日期：2026-09-26
- 固定版本：`genai = 0.6.5`

## 结论

使用 `genai` 承担 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini generateContent 的协议适配，但不让 SDK 接管 PopGlot 的安全边界。迁移按协议逐个进行，不做一次性替换。

第一阶段已经完成：依赖固定在稳定版；四种产品协议均显式绑定到对应 adapter；SDK 使用由 PopGlot 创建的隔离 HTTP client，禁止根据模型名猜测协议。

兼容性验证发现 `genai 0.6.5` 依赖 `reqwest 0.13`，而 PopGlot 当前生产网络层使用 `reqwest 0.12`。直接升级曾使本地重定向测试受到系统代理影响。因此两个版本暂时隔离，现有生产请求不切换；待代理和重定向语义通过一致性测试后再合并网络栈。

## 采用理由

截至 2026-09-26，项目约有 893 stars、185 forks、413,542 次 crates.io 下载，近 90 天约 168,721 次下载；仓库当天仍有更新。0.6 系列在 2026-05-22 至 2026-06-06 连续发布五个稳定版本，协议覆盖和维护速度都明显优于继续自行追赶每家请求格式。

风险同样明确：项目主要由社区维护；0.7 仍是频繁变化的 beta；SDK 会按模型名处理 reasoning 等字段，而自定义网关不一定遵循官方模型规则。因此只固定 0.6.5，不启用 beta，也不允许隐式协议推断。

## 保留在 PopGlot 的边界

- 出网许可、私网目标许可和密钥生命周期
- 同源跳转限制、TLS 选择、连接与总超时
- 禁止系统代理静默改写用户明确配置的服务地址
- 请求体和响应体大小上限
- 取消、有限重试和可重试错误分类
- Markdown/代码保护、翻译元数据协议及流式重组
- 日志脱敏和面向用户的错误文案

## 后续切换门槛

每一种协议只有在以下门槛全部通过后才能进入生产路径：

1. 固定请求快照与当前实现等价，不额外发送 reasoning/thinking 字段。
2. 流式文本、usage、错误体和取消行为通过回放测试。
3. 真实 OpenAI 兼容网关、Anthropic 与 Gemini 各完成一次授权的人工验证。
4. 重定向、响应上限、超时和隐私门禁仍由 PopGlot 测试证明。
5. 可按协议独立回退到现有 adapter，而不是整体回滚。

## 暂不采用

- 不跟随 `0.7.0-beta.*` 自动更新。
- 不在后台静默下载并替换运行时代码；桌面应用的依赖升级必须经过构建、测试和签名。
- 不把模型列表或模型名当作协议选择依据。
