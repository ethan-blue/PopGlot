# ADR 0030: 分阶段迁移到 genai 协议适配层

- 状态：请求构造已接入生产路径；传输与保真解析由 PopGlot 保留
- 日期：2026-09-26
- 固定版本：`genai = 0.6.5`

## 结论

使用 `genai` 承担 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini generateContent 的协议适配，但不让 SDK 接管 PopGlot 的安全边界。迁移按协议逐个进行，不做一次性替换。

四种产品协议的普通/流式、文字/图片请求体统一由 genai adapter 构造；`TranslationProvider::prepare/prepare_stream` 已调用该实现，原有四套请求体拼装已删除。端点和认证仍来自用户配置，不使用 SDK 生成的地址和认证信息。模型名按原值保留，不启用 SDK 的 namespace/推理后缀猜测。

genai 0.6.5 没有公开脱离传输的 adapter 调用，采用带校验的 vendor 快照，仅添加一个同步 `prepare_payload` 导出函数，不修改上游协议逻辑。详见 `vendor/genai/POPGLOT-PATCH.md`。上游高层客户端整段读取响应，部分解析会 trim 文本；因此保留现有受限 HTTP、SSE 完成/错误判断、原始空白保真处理。这里完成的是请求协议适配迁移，不声称高层客户端、流式解析、模型目录也已迁移。

原先的 reqwest 0.12/0.13 并存仅是依赖事实，不再构成请求构造迁移的阻碍。生产网络仍走明确配置了 no_proxy、同源跳转和大小限制的原有传输。

## 采用理由

截至 2026-09-26，项目约有 893 stars、185 forks、413,542 次 crates.io 下载，近 90 天约 168,721 次下载；仓库当天仍有更新。0.6 系列在 2026-05-22 至 2026-06-06 连续发布五个稳定版本，协议覆盖和维护速度都明显优于继续自行追赶每家请求格式。

风险同样明确：项目主要由社区维护；0.7 仍是频繁变化的 beta；SDK 会按模型名处理 reasoning 等字段，而自定义网关不一定遵循官方模型规则。因此只固定 0.6.5，不启用 beta，也不允许隐式协议推断。

## 保留在 PopGlot 的边界

- 出网许可、私网目标许可和密钥生命周期
- 同源跳转限制、TLS 选择、连接与总超时
- 禁止系统代理静默改写用户明确配置的服务地址
- 请求体和响应体大小上限
- 取消、有限重试和可重试错误分类
- Markdown/代码保护、翻译元数据协议及流式重组
- 日志脱敏和面向用户的错误文案

## 放行与后续门槛

本地开发构建已接通 SDK 请求构造；正式分发前须核对以下门槛，真实服务验收仍单独记录：

1. 固定请求快照与当前实现等价，不额外发送 reasoning/thinking 字段。
2. 流式文本、usage、错误体和取消行为通过回放测试。
3. 真实 OpenAI 兼容网关、Anthropic 与 Gemini 各完成一次授权的人工验证。
4. 重定向、响应上限、超时和隐私门禁仍由 PopGlot 测试证明。
5. 回滚使用上一版已验证的应用构建，不在请求失败时静默重发或切换协议。

## 暂不采用

- 不跟随 `0.7.0-beta.*` 自动更新。
- 不在后台静默下载并替换运行时代码；桌面应用的依赖升级必须经过构建、测试和签名。
- 不把模型列表或模型名当作协议选择依据。
