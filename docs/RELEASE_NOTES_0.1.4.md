# PopGlot 0.1.4 发布说明

发布日期：2026-09-05。基线：`feb77d5` 之后的全面评审整改（T00–T18），任务与证据见
`docs/review-2026-09-05/EXECUTION-LOG.md`。

## 主题

隐私、文本保真、数据可靠性与可验证性。本轮不新增大功能；每一项整改都对应
`docs/review-2026-09-05/REVIEW.md` 的一个编号缺陷，并以可复跑的测试锁定。

## 用户可感知的变化

- **授权更诚实**：内置免费引擎在未授权/已拒绝/离线时零出网（含健康探测）；授权入口在
  「设置 → 隐私与数据」，首次使用也有就地引导。
- **复制不再损坏代码**：`foo_bar_baz`、`__init__`、行内代码、路径逐字保留；主窗/浮窗/
  查词三入口复制同一约定文本。
- **不完整结果不落盘**：带警告、is_partial 或空译文的结果保持可见但不写历史、不自动
  复制、不触发朗读/收藏；流式中向上滚动不再被新增量拽走。
- **局域网分类诚实**：私网地址不再被当作"本机"；LAN 视觉服务需独立授权，措辞明示
  "发送到局域网另一台设备"。
- **朗读更准**：语言标签优先（`bonjour été` 走法语）、emoji 不再误判德语；停止立即取消
  在途合成；云端朗读需要独立授权（默认关，走 Windows 本地语音）。
- **收藏可靠**：写盘失败明确提示"未保存到本机，请重试"且不点亮星标；同一词不同语言对
  各自独立；代码标识符大小写保留。
- **主按钮白字、焦点可见**：修复隐式样式掩蔽导致的深色按钮文字（对比度 3.16:1）；
  焦点环换用高对比 FocusBrush。
- **长文可翻**：超过 800 字符的输入自动分段（代码块保持完整），顺序合并；取消后不再
  继续请求后续段。
- **启动性能可测量**：新增 `scripts/measure-startup.ps1`，实测 30 次启动到托盘可用
  P50=181ms / P95=200ms（预算 600/1200ms 内）。

## 兼容与迁移

- 配置 schema v7：v6 及更早版本首次运行自动无损迁移（.bak 保留原文件）；迁移不发明
  新权限，LAN 授权默认关闭，需用户显式开启。
- 星标身份从「仅词面」改为「词面+语言对」：既有收藏在升级后按原词面+语言对继续匹配；
  大小写从忽略改为保留（`Foo` 与 `foo` 视为不同标识符）。
- `VisionDirect` 语义变化：所选视觉服务不可执行时明确阻断并给出原因，不再静默回退
  本地 OCR（与 PRODUCT_SPEC/PRIVACY 同步）。
