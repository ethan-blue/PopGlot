# SDK 与产品复查

日期：2026-09-26。以当前代码与本轮测试为依据，旧台账中的“完成”不代表真机和真实服务验收。

## 本轮发现与处理

| 视角 | 发现 | 处理 |
| --- | --- | --- |
| 架构维护 | genai 原来只建客户端，生产请求没有使用 | 四种协议的普通/流式、文字/图片请求体均由 genai 0.6.5 构造，删除重复 JSON 拼装 |
| 可靠性 | 测试结束才读取配置，晚到结果可标记到新配置 | 开始时锁定编辑代次、配置和引擎；成功与失败均丢弃过时结果 |
| 交互 | 修改 Key 可重新启用正在测试的按钮 | 在途测试独立门控，重复点击不重复发送 |
| 产品状态 | 新 Key 的测试可能被写成已保存 Key 的验证证据 | 未保存 Key 的结果仅留在编辑草稿；换 Key 未测试则不继承旧证据 |
| 配置一致性 | 地址整体小写导致大小写不同路径共享验证 | URI 规范化保留路径大小写，回归覆盖 /API 与 /api |
| 阅读体验 | 资料库译文直接显示 Markdown 标记 | 复用翻译页文档渲染，支持标题、列表、代码块；渲染异常保留原文 |
| 文案与声音 | 预览和朗读包含 Markdown 语法 | 使用共享纯文本转换；存储内容不改写 |
| UI | 详情底栏文字按钮拥挤；空列表操作无效 | 朗读/复制使用共享图标，底栏可换行；空列表禁用清空/导出 |
| 文案 | “失焦隐藏”偏开发术语 | 改为“自动收起浮窗” |
| 依赖治理 | SDK 高层读取无本产品大小限制，解析可能 trim | SDK 只负责协议构造，保留有界传输和逐字保真解析；vendor 仅一个导出补丁，提供原始包哈希与校验脚本 |

## 迁移边界

已迁移：OpenAI Chat、OpenAI Responses、Anthropic Messages、Gemini 请求体构造，正常生成与流式生成均走生产调用链。SDK 不接触真实 Key；保留用户端点、自定义请求头及 Anthropic 版本。

保留：本产品 HTTP 发送、认证、出网许可、同源跳转、取消、有限重试、请求/响应上限、SSE 完成判断、原文和代码保真。模型目录仍由现有目录服务处理。不能把本轮描述为“所有网络代码都改为 SDK”。

依赖来源与升级步骤见 `vendor/genai/POPGLOT-PATCH.md`。已用原始 crates.io 包校验 135 个源文件、许可证和唯一导出补丁。后台热替换依赖不适合当前原生桌面架构；SDK 更新随应用构建验证和分发。
