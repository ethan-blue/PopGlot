# PopGlot 0.1.1 发布说明

0.1.0 之后的修复与打磨版本：修复流式输出丢帧、视觉请求误报失败、
快速切换菜单崩溃等关键缺陷，新增右下角引擎快速切换器与「视觉识别 +
文本模型翻译」两段式截图管线，并全面统一主题配色与界面细节。

## 新增

- **右下角引擎快速切换器**：主窗口底部点击引擎状态即可在已配置的文字/图片引擎之间一键切换，
  免去进入设置页；内置免费引擎（仅文字）也可显式选为当前线路，并附最近一次连通探测结果。
- **「视觉识别 + 文本模型」截图管线**：视觉模型只负责识别截图文字，译文由文本模型流式生成；
  自动模式下本地 OCR 不可用且使用云端视觉服务时默认优先该管线。
- **设置新增该模式选项**（隐私与数据 → 截图处理方式）。
- 新增回归测试：菜单样式非法 Role 触发器、OpenAI 流式末帧携带正文的场景。

## 修复

- **流式输出整条一次性出现 / 短译文截断**：OpenAI 兼容流在携带 `finish_reason` 的最后一帧里
  的正文被丢弃，短翻译（含视觉模型回答）整段丢失或零增量。
- **视觉模型请求成功却显示失败**：视觉草稿调用的独立视觉密钥传参为空导致鉴权失败；
  以及上述末帧丢字导致的空译文误判。
- **点击右下角快速切换菜单即崩溃**：MenuItem 隐式样式使用了 `MenuItemRole` 不存在的
  `Separator` 值，首个菜单项加载样式时进程直接退出。
- **设置窗口退出路径卡死**：托盘退出时设置窗口的未保存草稿守卫与 `Shutdown()` 相互纠缠。
- **切换引擎/切换语言时界面卡顿**：设置持久化（Rust 侧写盘含 flush+rename）从 UI 线程
  移到后台排队执行。
- **免费引擎误报“尚未配置文本模型”**：无引擎档案时不再从旧版默认凭据槽取残留 key。
- **翻译面板底部状态与耗时串重叠**、设置窗口底栏状态与保存按钮重叠：改为两列布局。
- 面板关闭后不再钉住截图字节数组（内存驻留随使用次数增长的问题之一）；
  主窗口最小化到托盘与面板关闭时释放工作集。
- 引擎编辑器里应用预设后立即判脏、返回被“未保存修改”守卫拦截的问题（新建流程）。

## 变更

- **主题**：品牌强调色换为 azure 蓝系（深色 #4D9FFF / 浅色 #1A63D8），主按钮为深一档的
  品牌蓝配白字；App.xaml 种子色板与 ThemeService 正式色板逐项同步，消除启动/切换时的不同步。
- **界面统一**：原文/译文卡片同底色同边框；次级按钮升级为带边框可见样式；危险按钮配
  危险色浅底；引擎编辑器内联选项升级为拨杆开关；引擎列表行防碰撞、键盘焦点可见；
  语言交换按钮在空闲态不再禁用；多处状态文字补悬停提示。
- 免费引擎缓存满 256 条时逐条淘汰而非整表清空；模型推荐 chips 刷新防抖。
