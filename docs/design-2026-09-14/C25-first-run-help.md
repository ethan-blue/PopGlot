## 1. 目标与非目标

### 1.1 目标
1. **首次启动三步引导（First-Run Onboarding）**：首次启动且未配置任何服务时，弹出轻量三步引导（非全屏强阻断模态，可随时跳过直接使用）：
   - 步骤一（欢迎与理念）：简洁介绍「快捷翻译工具，数据严格保留在本机」；
   - 步骤二（引擎配置直达）：提供快捷选择「使用内置免费引擎（需明确勾选知情授权）」或「配置自定义 API Key」；
   - 步骤三（快捷键速览）：醒目展示划词（Alt+D）、截图（Alt+S）、查词（Alt+W）默认热键，并提供「试一试」本地模拟演示。
2. **离线内置帮助体系骨架（Offline Help Skeleton）**：
   - 建立结构化的离线 Markdown 帮助文档，用户在无网环境下点击「帮助」可即时呼出浏览，包含快速入门、隐私说明、热键指引与故障诊断。
3. **演示内容防伪标注规范（Demo Transparency）**：
   - 在首次引导或示例体验中展示的所有翻译样例，显式水印或灰色徽章标注：`[演示样例 · 未联网]`，杜绝让用户误以为软件在未经允许的情况下已偷偷发送了网络请求。

### 1.2 非目标
1. **强制注册与在线登录**：绝不强制用户注册 PopGlot 账号，跳过引导后所有本地功能完全畅通。
2. **在线文档重定向**：不强制跳往外部浏览器网页，所有核心指引内嵌在程序资源包内。

## 2. 交互流与首次体验设计

### 2.1 引导流转图
```text
[检测到首次运行: ShellSettings.HasCompletedOnboarding == false]
                       │
                       ▼
            打开 OnboardingWindow (轻量向导)
                       │
    ┌──────────────────┼──────────────────┐
    ▼                  ▼                  ▼
[1. 欢迎与隐私]   [2. 选择引擎]      [3. 掌握热键]
- 本地优先承诺    - 内置免费引擎     - Alt+D (划词)
- 零遥测声明      - 自定义 API Key   - Alt+S (截图)
                  - 稍后自行配置     - 示例本地演示 [演示·未联网]
                       │
                       ▼
            点击「开始使用 PopGlot」
                       │
            HasCompletedOnboarding = true
                       │
            静默收缩至托盘，浮窗就绪
```

## 3. 离线帮助文档目录结构骨架

将在后续波次落地的离线文档大纲规划如下：
```text
docs/help/
├── index.md                 # 帮助首页与快速导航
├── getting-started.md       # 3 分钟快速上手指南（三快捷键用法）
├── privacy-and-security.md  # 隐私边界、存储目录与出网授权说明
├── keyboard-shortcuts.md    # 完整快捷键表与热键冲突排查
├── provider-setup/          # 常见翻译引擎配置教程
│   ├── deepseek.md          # DeepSeek API 配置指引
│   ├── openai.md            # OpenAI / Azure 配置指引
│   └── local-models.md      # Ollama / LM Studio 本地部署连接指引
└── troubleshooting.md       # 常见故障排查（自启失效/热键注册失败/权限问题）
```

## 4. 验收清单与涉及文件

### 4.1 验收清单
- [ ] **3分钟完成度**：新用户在无任何配置下启动，3 分钟内可通过内置引擎或示例成功完成一次模拟取词翻译。
- [ ] **演示透明度**：所有内置测试用例文本旁均带有醒目的 `[演示 · 未联网]` 标识。
- [ ] **离线可读性**：在断网环境下点击「设置 -> 帮助」，本地文档界面毫秒级打开，排版完整无排版错误。
- [ ] **跳过与重置**：点击「跳过向导」可立即关闭；设置页提供「重新打开新手引导」按钮。

### 4.2 涉及文件清单
1. `apps/PopGlot.Windows/OnboardingWindow.xaml(.cs)`（新建向导窗口）
2. `apps/PopGlot.Windows/ShellSettings.cs`（增加 `HasCompletedOnboarding` 标记）
3. `docs/help/`（建立离线文档骨架大纲）
