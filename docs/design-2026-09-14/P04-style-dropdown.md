# P04 主界面风格选择器与切换语义设计方案

> **设计日期**：2026-09-14  
> **责任角色**：Pi（W20b 设计先行 / 前端 UI 设计）  
> **依据合同**：`docs/review-2026-09-12/PROMPT-PERSONALIZATION-AND-GLM-HANDOFF.md` §3.1、§4.4、§7 P04；引用 G08（请求不可变与保存语义）、G04（缓存防穿透）  
> **覆盖范围**：主工作台（`TranslateSection`）、快捷划词浮窗（`TranslationPanelWindow`）、极速查词栏（`QuickSearchWindow`）三大多端交互视口。

---

## 1. 目标与设计定位

### 1.1 核心原则
1. **次要入口、默认低噪**：默认显示当前选定风格（出厂默认「✨ 忠实翻译」），无需前置配置即可直接使用；不喧宾夺主，不破坏现有语言交换与核心翻译主路径。
2. **严守 G08 切换语义（下次翻译生效）**：
   - 切换风格**仅改变下一次发起的翻译请求**（Next Request Effective）；
   - **绝不自动重译在途请求**，绝不中断正在进行的流式渲染；
   - 绝不因点击风格切换而向后台发送任何网络刷新请求。
3. **最近使用（MRU）轻量维护**：下拉面板或浮层优先展示「最近使用的最多 5 项模板」，随后提供「系统内置」与「管理偏好…」直达跳转。
4. **引擎能力诚实退化**：当用户选定的翻译引擎为不支持自定义 Prompt 的纯 HTTP 直译服务（如内置免费 Google 翻译）时，风格选择器显式退化为禁用/不可选状态，并说明原因，绝不伪造支持。

## 2. 方案对比与架构推荐

为解决三类不同尺寸与交互密度窗口的风格呈现，本设计深入评估两套主流交互范式：

### 2.1 方案对比矩阵

| 评估维度 | 方案 A：轻量 ComboBox 下拉框 | 方案 B：胶囊徽章（Capsule Pill）+ 上下文浮层（ContextMenu） |
|---|---|---|
| **视觉呈现** | 传统表单控件，带边框、文字、下三角箭头；宽度固定（110~140 DIP） | 紧凑型胶囊徽章（Padding 6,3，高度 24 DIP），仅文字+极小下拉标记 |
| **空间占用** | **较大**。在 320 DIP 浮窗或查词窗口中易挤占语言标识与操作按钮热区 | **极小**。自适应文字宽度，视觉噪音接近标签徽章，无笨重边框 |
| **层级与分类** | WPF 原生 ComboBox 对分组标题（内置/最近/自定义）支持较为笨重 | `ContextMenu` / `Flyout` 极易构建带标题、分隔线、快捷入口的分层菜单 |
| **触控与焦点** | 下拉展开受父容器 `ClipToBounds` 约束，高分屏下容易产生裁切 | 顶级窗口浮层，天然穿透窗口边界，支持键盘方向键无缝导航 |
| **退化态展示** | 仅置灰，无法在项右侧附加「不支持」的友好解释说明 | 菜单项可清晰展示子标题与「当前引擎不支持个性化偏好」详细 ToolTip |

### 2.2 推荐架构决策：混合适配方案
依据「不同视口匹配最佳密度」准则，制定如下设计规范：
1. **主工作台（`TranslateSection`，桌面大视口）**：
   - 采用 **方案 A 升级版（扁平胶囊 ComboBox）**。放置于目标语言栏右侧，与语言选择器排版呼吸感一致，适合鼠标大范围稳定点选。
2. **划词浮窗（`TranslationPanelWindow`）与极速查词（`QuickSearchWindow`，紧凑/瞬态视口）**：
   - 统一采用 **方案 B（胶囊徽章 + ContextMenu）**。直接紧随 `EngineBadge` 或 `LangBadge`，既展示当前风格状态，点击又可快速唤起微型气泡菜单，绝对不挤压标题栏宝贵热区（严格守住 WIN-05/WIN-17 ≥32 DIP 触控规范）。

## 4. 切换语义与请求一致性合同（G08 契约落实）

### 4.1 切换时效性（严格遵循「下次生效」）
1. **进行中请求（In-Flight）不可变性**：
   - 若当前已有翻译请求在途（Stage 为 `Translating` 或 `Streaming`），用户此时切换风格下拉，**仅更新当前界面的 `SelectedTemplateId` 状态**；
   - 正在输出的流式结果继续按照发起时的 Prompt 模板渲染完成，绝不中途打断、绝不切换为新模板的编译指令。
2. **零自动重译**：
   - 切换风格项不会自动触发重新翻译（区别于语言交换按钮）；
   - 用户如需用新风格翻译当前内容，需明确手动按下 `Enter`、点击「重新翻译」图标或再次唤起热键。

### 4.2 缓存击穿防护（G04 契约落实）
- 风格切换后，下一次翻译计算缓存 Hash 时，严格将 `TemplateId` 与 `TemplateRevision` 纳入键值哈希；
- 绝不因原文本相同而错误命中旧风格的缓存译文。

### 4.3 引擎不支持时的退化状态（Graceful Degradation）
1. **能力嗅探**：
   - 若当前激活的引擎为内置免费翻译（`ProviderKind == FreeBuiltIn`）或不支持自定义 System Prompt 的受限端点；
2. **UI 显式反馈**：
   - 风格徽章文字变更为 `[偏好已停用]`（Foreground=`TextDisabledBrush`）；
   - 徽章背景置为透明，边框置为浅灰虚线；
   - 鼠标悬停 ToolTip 明确提示：「当前引擎（内置免费公共翻译）为纯文本直译，不支持提示词偏好。如需启用个性化风格，请前往设置切换为大模型引擎。」；
   - 点击时菜单仍可展开，但顶部显示黄色 Warning 条提示上述信息，且各风格项置灰不可选，底部保留「配置翻译引擎…」跳转项。

## 5. 控件规格与 Design Token 映射表

| UI 组件/元素 | XAML 控件 | 样式或属性 | 颜色/尺寸 Token |
|---|---|---|---|
| 主窗风格下拉框 | `ComboBox` | `Style="{StaticResource StylePickerComboBox}"` | MinWidth 110, Height 26, CornerRadius 6 |
| 浮窗/查词风格胶囊 | `Button` | `Style="{StaticResource StatusPillButton}"` | Height 24, Padding 6,2, CornerRadius 6 |
| 胶囊背景（默认） | `Border` | `Background="{DynamicResource SurfaceRaisedBrush}"` | 悬停 `SurfaceHoverBrush`，按下 `SurfacePressedBrush` |
| 胶囊文字与图标 | `TextBlock` / `Path` | `Foreground="{DynamicResource AccentBrush}"` | 字号 11.5px，SemiBold，对比度 ≥ 4.5:1 |
| 菜单宿主容器 | `ContextMenu` | `Style="{StaticResource ModernContextMenu}"` | 背景 `SurfaceBrush`，边框 `BorderSubtleBrush`，圆角 8 |
| 菜单分组标题 | `MenuItem` | `IsEnabled="False"`，独立 HeaderTemplate | 前景 `TextTertiaryBrush`，字号 11px |
| 活跃选定项标识 | `Path` (IconCheck) | `Fill="{DynamicResource AccentBrush}"` | 12×12 DIP，位于文本左侧 |
| 不支持退化态背景 | `Border` | `Background="Transparent"`，边框 `BorderSubtleBrush` | 文字 `TextDisabledBrush` |

## 6. 交互状态机（Style Selector State Machine）

```text
             +----------------------------------------------------+
             |            Initialize (读取当前配置)               |
             +----------------------------------------------------+
                                      |
                                      v
             +----------------------------------------------------+
             |            ActiveReady (展示当前有效风格)          |
             +----------------------------------------------------+
               |                           |                    |
          引擎不支持                  用户点击徽章           发生外部配置同步
               |                           |                    |
               v                           v                    v
+-----------------------------+  +-------------------+  +------------------+
| Disabled / Unsupported      |  | DropdownOpened    |  | RefreshDisplay   |
| (置灰显示, ToolTip 明确告知)|  | (展示 MRU + 分类) |  | (更新文字与徽章) |
+-----------------------------+  +-------------------+  +------------------+
                                           |
                                      选择新风格项
                                           |
                                           v
                                 +-------------------+
                                 | UpdateCurrentSlot |
                                 | (更新本地槽位,    |
                                 | 下次请求生效,     |
                                 | 不重发在途请求)   |
                                 +-------------------+
```

## 7. 验收清单（Definition of Done）

1. [ ] **三视口呈现一致**：
   - `TranslateSection`、`TranslationPanelWindow`、`QuickSearchWindow` 均能清晰展示当前生效风格（名称 + 图标）；
   - 高分屏（125%、150%、200% DPI）下无文字裁切与折行。
2. [ ] **G08 请求隔离断言**：
   - 在流式翻译进行期间切换风格，当前翻译文字与说明正常结束，不被中止，不改变当前请求的 Prompt 标识；
   - 紧随其后发起的下一次翻译，成功带上新选定风格的模板 ID 与 Revision 快照。
3. [ ] **MRU 环形队列行为**：
   - 最近使用的 5 个模板准确置于下拉顶部；
   - 模板在设置页被删除后，MRU 队列自动移除该项；若当前选中的正是被删除项，安全回退至内置「✨ 忠实翻译」。
4. [ ] **免费引擎退化诚实性**：
   - 切换到内置公共免费引擎时，风格徽章立即转为禁用态，提示「当前引擎不支持个性化偏好」，杜绝伪造支持。
5. [ ] **键盘与无障碍焦点**：
   - 支持键盘 Tab 键聚焦到风格选择器，按 `Enter` 或 `Space` 展开菜单，方向键上下选择，`Esc` 关闭并归还焦点。
