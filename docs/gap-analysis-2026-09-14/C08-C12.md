## 1. 逐项详析

### C08 商业安装路径与自启修复（P1）—— NOT_STARTED

**合同条款**（§8 L352–364）：
1. 安装器负责安装目录、开始菜单、卸载、升级和启动注册迁移；
2. portable 模式明确提示「移动文件夹会影响开机启动」，启动时只修正 Run 路径，不覆盖 OS 禁用；
3. 发布包内每个 PE/native DLL 一致版本、架构和签名策略；
4. 升级失败可回滚，数据目录与二进制目录分离；
5. 产品决定：签名 MSIX/Store 或签名安装器二选一并写 ADR；
6. 验收：全新安装、覆盖升级、降级拒绝/回滚、移动 portable、卸载数据选择、标准用户权限矩阵。

**现状**：
- **无 ADR**：全 docs/ 无任何 ADR 文件（`find docs -iname "*adr*"` 为空）；MSIX/Store vs 安装器的产品决定未做。
- **发布形态仍是未签名便携 zip**：`docs/RELEASE_NOTES_0.1.5.md:25` 明示「本版本发布的是未签名便携 zip，不是签名安装器」且「不包含自动更新服务」。`artifacts/` 与 `dist/` 下均为 zip/dll 平铺，无安装器工程。
- **条款 2 的后半句已由 C07 兑现**（非 C08 领取）：`StartupRegistration.cs:285 RepairRunPath`、`:269`（`state.PathMatches || RepairRunPath()`）、`:383`（`StartupSaveAction.RepairPath => RepairRunPath()`），配合 A01 PlanSaveAction 的「OsDisabled 时不写注册表」，即「启动时只修正 Run 路径、不覆盖 OS 禁用」。但「portable 模式明确提示移动文件夹会影响自启」的 UI 提示不存在（`GeneralSection.xaml`/`StartupRegistration.cs` 全文 grep「移动」零命中）。
- 条款 1/3/4/6（安装器、签名一致性、回滚、数据目录分离、权限矩阵）无任何实现或排期证据。

**判定理由**：C08 本体（安装渠道决定与安装器）零实施；唯一的重叠项（Run 路径修正语义）属 C07 返修（A01–A03）成果，不构成 C08 领取证据。台账 §2 标 SPECIFIED_NOT_IMPLEMENTED「未领取」**属实**。
