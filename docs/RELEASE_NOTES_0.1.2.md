# PopGlot 0.1.2 发布说明

0.1.1 的稳定性修复版，重点解决在不同 Windows 电脑上使用划词、截图和
快捷键设置时可能出现的 UI 假死或快捷键静默失效。Windows x64 便携包现在自带
.NET 10 Desktop Runtime，下载解压后即可运行。

## 修复

- **划词后窗口假死**：剪贴板 OLE 读取移入独立 STA 工作线程，延迟渲染提供者超时时不再阻塞 UI。
- **剪贴板完整性**：无法完整快照所有原始格式时直接取消划词，不发送合成 Ctrl+C，避免清空或丢失原剪贴板数据。
- **连续重试的线程累积**：超时工作者真正退出前保持单工作者熔断，防止连续按热键不断创建卡住的 STA 线程。
- **截图时 UI 卡顿**：`CopyFromScreen` 和 PNG 编码移到后台，改善 4K、多屏与远程桌面环境。
- **设置保存卡顿**：策略与 Shell 设置写盘异步化，慢磁盘和杀软扫描不再阻塞窗口。
- **快捷键恢复失败**：批量注册冲突原子回滚，托盘和主窗口明确提示冲突；保留原配置，冲突解除后可再次恢复。

## 发布与兼容性

- 便携包改为 **self-contained Windows x64** 发布，无需预装 .NET。
- 支持 Windows 10 19041 及更高版本、Windows 11 x64。
- 配置 Schema 不变，可直接覆盖旧版程序文件，用户配置无需迁移。
