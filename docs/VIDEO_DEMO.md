# PopGlot：90 秒公开演示视频

## 本轮 UI 到底改了什么

0.1.21 是交互修复，不是视觉重设计：

- 工作台、浮窗同步语言，查词使用保存的语言。
- 切语言清掉旧译文、说明和要点显示，避免旧内容重新出现。
- 明显错误语言的结果显示具体警告，不自动重复收费。

录制时不要使用「全新 UI」「已解决全部翻译问题」等不符合当前实现的说法。0.1.21 未上传 Release 前应标注「待发布 / 开发预览」。

## 用什么录

- **OBS Studio**：录窗口画面和麦克风，免费开源。使用「窗口采集」选 PopGlot；演示浮窗或截图遮罩时，先确认这些独立窗口能被采集，必要时在清理过的专用桌面使用显示器采集。
- **剪映**：剪掉等待时间、加中文自动字幕和配音。具体功能及收费以安装版本为准。
- **ScreenToGif**：适合另做 10～20 秒无声 GIF，放 GitHub README；不替代有声音讲解的完整视频。
- 只想快速试录可用 Windows 录制工具，但先检查能否录到独立浮窗和截图遮罩，不能只凭预览主窗口判断。

建议 OBS 先录 MKV，完成后用其「录像转封装」导出 MP4，减少意外退出损坏整段视频的风险。最终上传 H.264 MP4，横版 1920×1080、30 fps 即可；竖版重新安排画面，不拉伸横版。先录 10 秒检查文字清晰度、声音和浮窗捕获。

## 录制前隐私检查

1. 从托盘退出正在运行的 PopGlot，避免单实例把演示请求转交给日常实例。
2. 关闭聊天、邮箱、通知预览及含个人路径的终端，使用无隐私的演示素材。
3. 可为演示单独设置配置目录，再启动便携版：

   ```powershell
   $env:POPGLOT_DATA_ROOT = Join-Path $env:TEMP 'PopGlot-Video-Demo'
   Start-Process .\PopGlot.exe
   Remove-Item Env:POPGLOT_DATA_ROOT
   ```

   这只隔离 PopGlot 的配置、历史等文件，不隔离 Windows 凭据管理器或外部 OMP/Codex 的账号。需要完整隔离时使用专门的 Windows 演示账号。
4. 使用单独的演示引擎和测试文本。配置服务、填写密钥、浏览器授权、粘贴回调全部在录制前完成；不要在视频中显示账号页、密钥输入框或完整诊断日志。
5. 录真实服务需要自行确认联网授权和可能产生的费用。测试夹具或模拟响应必须标注「演示数据」，不能冒充真实翻译效果或真实响应速度。
6. 本项目没有生成旁白、自动录屏或一键上传的内置功能；下文是拍摄脚本，不是已经录好的视频。

## 90 秒分镜

| 时间 | 画面 / 操作 | 口播重点 |
| --- | --- | --- |
| 0～8 秒 | 标题「PopGlot：Windows 划词与截图翻译」，主窗口干净画面 | 选中文字或框选截图，快速查看译文。 |
| 8～28 秒 | 在记事本选中下方英文，按 Ctrl+Alt+W，展示浮窗译文 | 不必把整段文字搬进聊天窗口。等待过程可剪短，标注「等待已剪辑」，不伪造实时速度。 |
| 28～45 秒 | 打开工作台与浮窗，把目标语言从中文切到英语，展示两处同步 | 这版修复了不同窗口语言不一致。自动检测只检测原文，不会自动把中文改翻成英文。 |
| 45～62 秒 | 使用自制英文图片，Ctrl+Alt+Space 框选，展示取字后的翻译 | 默认优先本地 OCR；只有授权相应视觉线路才会上传截图。本地 OCR 的可用语言取决于系统语言包。 |
| 62～76 秒 | 如需展示 OMP：只展示扫描到工具、已选模型和测试结果，不展开账号授权 | 支持原生版与官方 Bun 包入口；翻译仍使用工具配置的服务和额度。没有可用实机环境就跳过本镜头，不用假登录画面。 |
| 76～90 秒 | 主窗口收尾，加项目地址、版本和下载提示 | 这次是语言状态、OMP 兼容和识别边界修复。欢迎反馈具体原文、目标语言和引擎名称，不要提交密钥。 |

### 可公开使用的素材

英文划词：

> Please restart the application before changing the translation settings again.

中文反向翻译：

> 请先重新启动应用程序，然后再修改当前使用的翻译设置。

截图文本（自己在记事本或图片编辑器排版，不使用他人私人页面）：

> Connection timed out. Check your network settings and try again.

演示错误语言警告不是必选镜头：它依赖模型实际输出，不能为了凑镜头把假的错误或警告剪成真实运行结果。

## 可直接调整的旁白

> 这是 PopGlot，一个 Windows 划词和截图翻译工具。选中英文，按快捷键，就能在旁边查看译文；也可以打开工作台，编辑原文和目标语言。这次修复了工作台、浮窗和查词之间语言不一致的问题，切换语言后，旧译文和说明也不会再重新出现。截图默认优先在本地识别，识别语言依赖 Windows 的 OCR 语言包。你可以配置自己的翻译引擎，也可以连接支持的 OMP 工具。需要注意，自动检测针对的是原文语言，中文翻英文仍要选择英语目标。项目和下载链接放在简介，欢迎带着具体样例反馈问题。
