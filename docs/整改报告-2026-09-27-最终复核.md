## 排版链路与全局 UI 验收

显示层没有恢复按标点吞并普通换行的逻辑。此次只修改 Markdown 复制/渲染格式化器；提示词、模型原始响应、协议解析、完整历史写入及导出链路未进行逐阶段新建的固定响应夹具验收。历史不做批量改写。现有 LogicTests 有流式、终态与历史行为覆盖，但不等同于完整链路结构一致性证明。

工作台、引擎列表/编辑、规则页、通用设置、隐私与数据、资料库、浮窗、查词和离线帮助已有当前工作区生成的深浅主题及 125/150/200% 离屏截图，路径为 `artifacts/screenshots/`。这些图可以核对布局与内容，不能证明真实 IME、读屏、多显示器混合 DPI 或全部鼠标状态通过。API Key 状态真实存储、模型列表靠近屏幕边缘的弹层及所有设置入口仍需针对 0.1.11 构建做人工回归。
