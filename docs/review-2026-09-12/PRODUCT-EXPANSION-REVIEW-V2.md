## 1. 产品判断

当前具备一个翻译工具的基础能力：四个输入入口、流式翻译、OCR、历史、生词、服务配置和主题。下一步最重要的是把这些入口串成完整的日常工作过程：获取内容、校对输入、选择语言、得到可信结果、复制使用、出错恢复、下次找回。

第一轮主要回答“哪里坏了”，缺少“用户下一步要做什么”。例如有生词收藏，不代表有可编辑、可复用的术语库；有历史，不代表可以恢复未完成的浮窗；有截图，不代表可以调整误选区域或校正识别结果；支持多个 Provider，不代表用户能理解当前请求的来源、费用和可用性。

产品定位建议：优先服务经常跨应用阅读资料、报错、技术文档和外语内容的 Windows 用户；也支持普通短句和日常阅读。先把这条使用链做顺，再扩展文档翻译、学习系统和多设备能力。

### 1.1 目标用户与成功任务

| 用户情境 | 希望完成的事 | 成功标准 | 当前主要缺口 |
|---|---|---|---|
| 阅读网页/文档 | 选中文字快速看懂，再回原应用 | 两次以内主动操作看到结果；来源选区不丢；不必进设置 | 复制目标窗口、焦点、失焦恢复 |
| 调试代码 | 翻译报错且保留可运行内容 | 标识符、缩进、路径不改写；解释与译文分开 | 保真、复制模式、解释可信度 |
| 阅读截图 | 框选、校对识别、翻译 | 小误选可以调整；识别错误可修；上传范围明确 | 选区调整、OCR 校对 |
| 编辑邮件/短文 | 控制语言与表达方式 | 输入换行不误发送；原稿与译文都可恢复 | 提交快捷键、风格、版本 |
| 经常遇到专业词 | 固定译法并重复使用 | 生词可编辑；术语确实参与下一次翻译 | 生词与术语职责不清 |
| 长期后台使用 | 登录后随叫随到 | 启动状态真实；睡眠/Explorer 重启后能恢复 | 生命周期与分发 |

| 入口 | 观察 | 证据边界 | 关联任务 |

## 3. 产品规则：先统一再新增

### 3.1 术语和数据责任

| 对象 | 定义 | 是否默认持久化 | 生命周期 |
|---|---|---|---|
| 输入草稿 | 用户正在编辑、尚未提交的文本 | 否 | 当前进程，用户显式清除或退出结束 |
| 会话 | 一次请求的输入快照、语言、风格、服务、输出和状态 | 否 | 按 N01 有界暂存 |
| 历史 | 已完整完成且符合历史策略的结果 | 沿用用户已有历史选择 | 受数量、时间、字节限额约束 |
| 生词 | 用户明确收藏并可编辑的学习内容 | 是，保存成功才显示收藏 | 用户删除前保留，受配额约束 |
| 术语 | 用户配置的源词→目标译法规则 | 是 | 只在启用并匹配的翻译中使用 |
| 原文图片 | 当前截图任务的源图像 | 否 | 当前 OCR/视觉任务期间；暂存规则见 N01 |
| 备份 | 用户主动导出的可恢复数据包 | 用户选择后生成 | 用户选定位置；不等于自动云同步 |

### 3.2 请求不可变规则

按下翻译时冻结输入、语言、服务、风格、术语版本和请求 ID。修改下拉框只影响下一次请求，不自动把当前输出标记成新服务的结果。任何“重新翻译”生成新 request/epoch，旧回调不得覆盖新画面。

权限与内容快照分开：请求内容可以冻结，发送许可仍必须在每个发送边界核验。撤销不能收回已经发送的数据，界面不能声称“从未发送”。

### 3.3 用户界面信息结构

- 一级导航维持“翻译、资料库、设置”；术语放资料库子页，不新增一排顶级导航。
- 翻译区：语言对与主动作、输入/结果、状态；“风格、复制格式、重新翻译”集中在各自相关位置。
- 设置：外观与交互、启动与快捷键、翻译服务、联网与隐私、存储与诊断。
- 对用户优先显示“未配置、可使用、上次检测失败、Windows 已禁用”；地址、reason code 和版本细节折叠。
- 新增功能必须有空态、禁用原因、失败恢复、键盘路径；只有一个正常截图不算完整设计。

以下为建议采纳的产品合同，未来实现后用真机验收。窗口可见性和后台请求状态不得共用一个 `closed` 字段。

| 事件 | 主窗口 | 翻译浮窗 | 极速查词 |

| 点击 X | 隐藏到托盘；若用户选了退出行为则走退出守卫 | 隐藏；在途请求取消并保留 partial | 同浮窗 |

| 同进程菜单、语言下拉、IME 临时窗口 | 不销毁会话 | 不视作外部关闭意图 | 同浮窗 |
| 托盘“退出 PopGlot” | 汇总任务和未保存设置后一次守卫 | 纳入同一退出过程 | 纳入同一退出过程 |
| 快捷键“恢复最近浮窗” | 不新发请求 | 恢复同一会话、选择与滚动 | 若最近是查词，恢复查词 |
| 重复“翻译选中内容” | 启动新的显式输入动作 | 旧会话暂存，新会话新 ID | 不等价于恢复 |

设置草稿的“保存/放弃/继续编辑”与翻译结果暂存分别处理。关闭应用只有一个总守卫，不能弹多层对话框。OS 注销/关机不得无限等待用户选择；有界取消任务并只保存用户事先允许持久化的数据。

## 5. 功能优化与新增任务规格

所有 N 任务当前状态均为 `SPECIFIED_NOT_IMPLEMENTED`。L1 为可靠可用版本，L2 为日常效率版本，L3 为后续增值版本；不是版本号或工期承诺。

### N01 会话暂存、误关恢复与工作台接续【L1；C05/C12/C14】

**用户收益**：切回原应用或误点关闭后能找回内容，无需重发请求。

**入口**：`App.CreatePanel/CloseActivePanel/ShowQuickSearch`、`TranslationPanelWindow`、`QuickSearchWindow`、`TranslationSession`。

**规格**：

1. 增加托盘“恢复最近翻译”；提供可选独立快捷键，默认不占用新的全局组合。
2. 自动隐藏只改变可见性；已启动的请求可继续至原 deadline，但不在隐藏期间自动复制、自动朗读或抢焦点；已启用历史时完整结果仍按原规则保存。
3. 显式 X/关闭快捷键取消在途请求，然后隐藏；取消后不写自动历史。恢复不会自动重试。
4. 内存暂存最多 5 个会话、累计文本最多 2MiB；隐藏且 30 分钟无访问后淘汰。容量先淘汰最旧非活动会话，不淘汰当前可见草稿来腾空间；超限显示原因。
5. 图像不进入隐藏会话仓库。正在执行的图片任务可持有其输入至完成/取消，然后释放；需要重试视觉请求时提示重新截图。恢复 OCR 文本可继续文字翻译。
6. 展开到工作台携带已有会话和结果，不发第二次请求；工作台有未提交草稿时先给保留/替换选择。
7. 退出清除内存暂存。跨重启恢复草稿作为后续独立显式选项，默认关闭。

**验收**：流式时 X→恢复得到 partial 且 send count 不增；自动隐藏→完整结果不改剪贴板；恢复保持语言、滚动、文本；关历史后恢复仍不落盘；超配额行为可见。

### N02 输入、IME、快捷键和来源复制【L1；C04/C10/C19】

**用户收益**：输入中文、换行、选中复制都符合预期，快捷键不会无故失灵。

**规格**：默认 Enter 翻译、Shift+Enter 换行，提供“Enter 换行、Ctrl+Enter 翻译”偏好；三入口统一并显示当前提示。组词中 Enter 仅确认候选，不提交；下一次真实提交键才发送。

`Ctrl+C` 有选区时复制选区，输入框无选区遵循编辑器行为，不劫持成复制整个译文；复制译文用按钮或明确专用组合。清空输入支持本地撤销，不能连带删历史。连续提交相同内容在同一活动请求中去重；再次修改后提交取消旧请求，旧回调无效。

划词开始捕获目标窗口，复制前再次核验前台；若用户主动切换窗口，停止复制并显示“目标窗口已改变，请重试”。不强抢焦点、不建议常态管理员运行。终端/受限文档提供手动粘贴路径。修饰键长按、UIPI、延迟剪贴板均有有界失败，不能发送到错误应用。

**验收**：中/英/日输入法，组词/非组词，粘贴多行、空输入、Ctrl+C 选区、修饰键长按、前台切换；每个操作记录实际请求数和剪贴板前后数据。

### N03 截图调整、OCR 校对与明确上传【L1 优化，L2 校对；C10/C23】

**现状**：存在截图与 OCR；当前松开鼠标即捕获，不代表拥有完整选区调整器。

**规格**：保留默认快速框选路径；另提供“框选后确认”模式。确认模式支持拖动选区和四角、Enter 确认、Esc 取消、重新框选；小于 6px 的误点回到等待框选而非直接消失。预览必须使用冻结的已捕获画面，避免用户确认 A 而实际发送后来的 B。

OCR 校对界面显示原图缩略图、可编辑文字、语言和“翻译文字”按钮；修正文本不重跑 OCR。清理断行、移除连字符只作用于用户选择范围，并可撤销；不得默认改代码缩进。没有可用置信度时不得编造百分比，用“请核对识别文本”。

网络动作前说明“只发送校对后的文字”或“将发送这张选区图片”。本地 OCR 不可用给安装指引和明确的替代选择，不能自动转上传。最近选区只记坐标与显示器标识，不自动再次截图；显示器变化后失效。

**验收**：误点、反向拖拽、跨屏、150%/200% 混合 DPI、负坐标、遮罩未混入源图、动态屏幕、取消不捕获/不发送、校对后发送内容等于修改文本。

### N04 阅读、复制格式与 partial 使用【L1；C04/C17】

**规格**：复制菜单提供“纯文本、Markdown 原文、仅所选内容”；代码块复制保留内部内容。默认纯文本的转换遵守 C04。译文与解释分别复制；不得把服务信息、水印或警告自动混入用户要粘贴的译文。

部分结果显示未完成；常规“复制译文”不可用，独立次要操作“复制已生成部分”明确提示可能缺失内容后允许用户主动复制。动作资格拆为自动副作用、完整结果操作、显式 partial 导出三类；不能放宽 `IsCleanCompletion`。

流式期间保留文本选择，向上滚动后停止自动跟随；显示“回到最新”而不把用户拉回底部。最终 Markdown 渲染保持阅读位置；大代码行可横向滚动，页面不能整体横向溢出。

**验收**：同一 fixture 三入口、三种复制格式逐字符验证；partial 手动操作不触发自动朗读/历史/收藏；终态渲染不清除正在选择的文本。

### N05 语言选择、翻译方向与风格【L1 语言，L2 风格；C13/C20】

**规格**：语言选择支持本地搜索、最近 5 项、收藏最多 5 项；只有源语言允许自动检测。自动检测结果不确定就写“未确定”，不将目标语言反写源语言。

源语言为自动时，交换只有在检测到具体语言后可用，否则说明原因；交换以完整译文作为新输入，保留原输入可撤销，不自动发送。选择新语言不会自动重译；“重新翻译”才产生新会话。

风格默认“忠实翻译”；可选“自然表达、正式书面”，放二级菜单。技术内容保护独立且默认沿用设置；风格不允许改变量/数字/路径。增加解释为独立选项，明确可能增加等待和费用。应用 UI 语言与翻译语言分开，中文优先，英文界面作为后续完整翻译任务。

**验收**：切语言不增请求；交换两次原文可恢复；请求 A 中改设置不改 A 的服务/语言标签；风格进入请求快照和缓存 key。

### N06 可编辑生词与真正的术语库【L2；C02/C20】

**现状**：已有生词存储/导出；未从已查 UI 路径确认完整术语编辑及请求应用链。实现前进一步检查 Core 术语协议，复用而非另建重复系统。

**规格**：生词支持编辑释义、备注、标签、源/目标语言；收藏默认不改变后续译法。单独“用于术语规则”动作生成待确认术语。

术语至少含 id、源词、目标译法、语言对、是否区分大小写、启用、更新时间；第一版只支持字面词/短语，不支持 regex。匹配优先长词再短词，语言对精确匹配；同范围重复冲突阻止保存并指向冲突条目。数字/代码保护高于术语替换，不能改受保护 token。

请求只携带实际匹配的启用术语；未用术语不出网。最多携带 100 条且额外载荷≤16KiB，超出时提示缩小范围，不能静默截断为“全部应用”。结果给“应用 X 条术语”详情；模型未遵守时标注需核对，不能伪造符合。

**验收**：最长匹配、大小写、不同语言对、禁用规则、冲突、注入式术语、保存失败、限额；术语版本变化使缓存失效。

### N07 历史检索、结果版本与清理【L2；C02/C11】

**规格**：在已有历史搜索上补来源/语言对/日期筛选与“仅收藏”视图；默认倒序，保留选中项 id 与滚动位置。无搜索结果应写“未找到匹配”，不能写“暂无历史”。

载入历史只展示旧结果，明确当时服务和时间；点“重新翻译”生成关联的新会话。历史保持原文/服务/语言快照，不随当前设置重标。批量导出/删除显示精确选中数，删除当前结果不撤销外部已发送请求。

单条删除提供 10 秒仅内存撤销；“立即清空所有数据”不保留撤销副本并明确提示。历史关闭后不新增记录，已有记录不自动删除；清理到期记录按既定保留规则，不偷偷扩大 200 条/90 天/4MiB 限额。

**验收**：过滤后删除正确 id；重载不跳选；历史禁用、到期、写失败、不完整会话各显示准确状态；导出只含选择范围。

### N08 备份、导入与本机恢复【L2；C02/C24】

**规格**：设置提供“导出数据备份”和“恢复备份”；默认包含用户勾选的历史/生词/术语/非敏感偏好，不含 Key、Header 秘密、日志、截图、启动绝对路径或会话暂存。

备份 manifest 有 schema、创建时间、文件列表、字节数与校验；导出前展示内容和敏感性提示。服务仅导出不含秘密的必要配置，恢复后标“需要重新填写凭据”。新导入的联网授权和自启默认关闭，不能从备份继承新授权。

恢复分预检→预览新增/冲突/跳过数量→用户选合并或替换→临时区校验→事务提交；发生失败保持当前数据不变。第一版只接受 PopGlot 自有 JSON 备份和生词 CSV；CSV 映射、编码、重复条目、公式字符均明示。压缩包解压必须限制路径、条数和解压后总大小；不能仅检查 zip 大小。

**验收**：跨版本、损坏 checksum、截断、同名 id、超大文件、磁盘满、路径穿越、恢复中取消；原文件 hash 在失败时不变。

### N09 朗读控制与语言真实性【L2；C23】

**规格**：播放/暂停（若引擎支持）/停止、语速、按语言可用语音列表；不支持暂停显示停止，不伪装。默认本地语音，云端需独立授权；未装目标语言语音时给选择/安装指引，不能静默用错误语言。

选中文本时明确“朗读选中内容”，否则朗读译文；原文有独立入口。新朗读取消旧合成和播放；隐藏/退出遵循窗口合同。合成有总 deadline、大小上限，取消后临时音频释放；回退保留语言标签。

**验收**：法语/中文/英文/混合文本、emoji、不可用语音、取消云合成、播放错误、重复播放；云权限撤销后后续发送 0。

### N10 当前服务、连接诊断与费用透明【L1 状态，L2 扩展；C16/C21/C23】

**规格**：翻译结果上显示实际使用服务，菜单切换只影响下一次请求。默认保存配置不联网；测试连接、获取模型各有明确按钮与取消。健康结果带时间且只作参考，不作为永久可用证明。

高级诊断区分 DNS、连接、TLS、认证、限流、超时，显示安全建议；默认使用系统网络配置，各协议一致性要验证。手工代理作为可选后续功能，不能为解决连接问题关闭 TLS 校验。

费用仅在存在可信价格与 usage 时展示，标来源和更新时间；不确定写“费用由服务商结算”，禁止把字符数换成精确收费。重复提交、重试、模型比较都可能额外调用；自动切付费服务默认关闭。

**验收**：模型目录失败仍允许保存手填模型；未知模型写能力待验证；任务切服务不改已发送请求；诊断复制不含 Key/query/source。

### N11 首次使用与无服务体验【L1；C25】

**规格**：首次主窗直接展示可操作工作台，非阻塞引导三步：输入方式、当前可用翻译服务、快捷键试用。允许跳过；输入草稿在前往配置再返回时保留。

离线演示使用本地预置输入/输出，醒目标“演示，未联网”，不进真实历史，不展示伪造耗时。首次真实翻译前展示实际接收方与发送范围；没有服务就地给“配置服务/仅提取文字”入口。不能引导用户开启所有隐私开关以求成功。

**验收**：无 Key、无 OCR、无网络、拒绝授权、已有旧配置五条路径；用户能描述下一步，不走死循环；引导隐藏后可从帮助重开。

### N12 设置搜索、修改语义与恢复默认【L2；C07/C15】

**规格**：设置搜索匹配中文名称/常用别名，定位到具体行并保留原导航；空搜索恢复原页。安全、启动、快捷键、服务修改均显式保存；主题可预览但退出草稿要还原。每个设置行标明生效时机。

保存过程只禁用提交相关操作，显示进行中；成功反馈对应实际已提交字段。自启写失败与其他设置已保存用逐项结果呈现，不把全部回滚/全部成功混为一谈。保存以版本号防止旧异步写覆盖新状态。

“恢复本页默认”先形成可查看的草稿；不删除数据、不清 Key、不扩大联网授权。热键冲突保留旧注册并说明冲突，恢复默认前也先验证冲突。

**验收**：修改再改回 clean、保存失败、连续改语言、关闭设置、应用退出、主题预览还原、组合键冲突。

### N13 专注模式与快捷键暂停【L2；C05/C07】

**规格**：托盘提供“暂停快捷键 15 分钟/直到手动恢复”，始终可从托盘恢复。应用启动时不自动恢复“直到手动恢复”以外的过期时长；计时用明确截止时间。录制快捷键临时暂停与用户主动暂停分开计数，关闭设置不能误恢复用户暂停状态。

通知仅用于明确需要用户处理的失败；后台翻译完成默认不抢焦点。全屏时不自动弹主窗，用户主动快捷键仍响应。第一版不做应用进程黑名单或记录用户使用轨迹。

**验收**：录制→保存失败→关闭，用户暂停→开设置→关设置，睡眠跨过暂停截止时间；可恢复且无后台轮询风暴。

### N14 布局密度、显示器记忆与缩放【L1；C13/C14/C18/C19】

**规格**：主窗内容宽度≥960 DIP 时左右分栏；720–959 支持紧凑侧栏；560–719 侧栏折叠且上下阅读；低于 560 以工作区边界为准降级，不能让操作跑出屏幕。断点最终以实测内容可读性确认，不以当前截图尺寸硬套。

默认正文 14–16 DIP，允许用户放大至 200%；字体放大与显示器 DPI 分开测试。源/译文允许拖动分隔比例，保留合理最小值，提供重置布局。长语言名可用自然简称+完整 tooltip，不截成“自动检/简体中”。

窗口位置保存逻辑矩形和显示器标识；恢复前夹到当前工作区，显示器拔出/任务栏改变后重新定位。浮窗拖动后停止自动追随光标；请求完成不得自行放大遮挡原应用。关闭、固定、更多之间有足够点击间隔，不能把整标题栏都当拖拽区。

**验收**：560/720/960/1440 宽度 × 短/长/错误，125/150/200% DPI，文本缩放、拔屏、任务栏方向变化、Tab 焦点顺序；主动作一直可达。

### N15 翻译质量验收与用户纠正【L2；C04/C20/C23】

**规格**：建立人工审阅的固定非隐私语料集：技术报错、代码注释、普通短句、专业术语、否定句、数值单位、歧义、OCR 噪声，每类至少 10 条。标识符逐字符保真与自然语言准确度分开评分；不把保护 token 全对等同于翻译质量高。

支持“编辑译文”作为本地人工版本，始终保留模型原始版本；编辑后不自动回传 Provider，不冒充模型输出。需要另一风格或再次生成时用户主动发起。纠正按钮先提供本地备注/复制诊断，默认不建立遥测后台。

**验收**：编辑/撤销/导出标明人工版本；金额、单位、否定/条件和代码误改是单独阻断；评审者和分歧记录可追溯。固定示例通过不代表所有输入质量有保证。

### N16 最近任务、长文进度与请求预算【L2；C20/C23】

**规格**：长文显示“第 X/Y 段、已完成部分、停止”，不显示虚假剩余秒数。第一版默认一个交互翻译任务，新的提交明确替换或保留旧任务；不在后台建立无限队列。

显示拒绝原因：输入过大、单个代码块超限、输出超限、服务限流；用户可缩小输入或分批。暂停/恢复仅在实现了段级输入快照、幂等合并和权限复核后提供，不把“重发全部”命名为继续。

**验收**：第 3 段失败/取消不发送第 4 段；恢复策略先用新请求显式重试未完成部分；合并顺序和段边界零丢字；总 deadline 覆盖所有 retry。

### N17 结果对照与第二服务复译【L3；N04/N10/N15】

**规格**：作为后续效率功能保留；用户明确点击后才把同一输入发往另一个已授权服务，展示接收方和可能增加调用。双结果各有来源/语言/时间，不把多数投票当正确答案。第二服务失败不清除第一份结果。

第一版不实现自动多模型仲裁、不自动连续请求最佳答案。验收覆盖独立取消、来源准确、Key 隔离、用户拒绝第二次发送。

### N18 文件翻译与学习扩展候选【L3 研究，不进入当前开发队列】

后续可评估 TXT/Markdown 批量翻译、文档对照、轻量生词复习。每项先独立立项：格式保真、长文本预算、费用、失败恢复和用户需求。PDF/Word 的布局、OCR、图表成本不同，不能承诺“支持文件翻译”后只做文本提取。

跨设备同步、账号、订阅计费、浏览器插件、hover 取词、实时视频/连续区域翻译、离线大模型保持候选列表，不成为当前“完整商业产品”的强制依赖。新增这些能力要另给产品合同；不能让轻量模型因本文提到就自行安装运行时或建立云服务。

## 6. 新增能力的数据与架构约束

继续沿用 WPF Shell + Rust Core。产品复审没有提供重写框架的理由。

- 窗口负责展示与焦点；会话仓库负责暂存/淘汰；协调器负责请求生命周期；存储负责事务结果，不能让 Window.Close 直接决定是否已保存。
- 共用操作资格应拆分为明确动作，避免一个布尔开关同时允许自动复制和 partial 手动导出。
- 会话新增 `settingsVersion/styleId/glossaryVersion/parentSessionId` 等概念时先确定序列化和迁移合同，字段名可以调整但语义不可省略。
- 不记录原文 hash 到普通日志：短文本 hash 可被字典反推。会话使用随机 ID，日志只保留必要长度/阶段/错误码。
- 缓存至少区分源文、语言、服务/模型、风格、术语版本、保护策略；权限撤销后缓存是否可读与是否可发请求分开处理。
- 不强行换数据库来“解决卡顿”；先测 JSON I/O、过滤和 UI 构建。真的需要 SQLite 时单独写迁移与回滚方案。

## 7. 优先级、依赖与轻量模型接力规则

### 7.1 可交付版本切片

| 阶段 | 范围 | 用户得到什么 | 不在该阶段强制实现 |
|---|---|---|---|
| L1 可靠日用 | C00–C07 关键修复，C09–C19 相关部分，N01/N02/N04/N11/N14，N03/N05/N10 的 L1 子集 | 启动可解释、输入可靠、结果不误丢、阅读可用 | 多模型对照、文件翻译、云同步 |
| L2 效率完善 | N03 校对、N05 风格、N06–N10 扩展、N12/N13/N15/N16 | 内容可整理、术语可用、数据可恢复、长文有反馈 | 账号或订阅不是前置条件 |
| 商业交付门禁 | C08/C22–C26 与已启用功能 E3 | 稳定分发、帮助、更新恢复、支持政策 | 安装渠道以实际决定为准，不强迫同时做两套 |
| L3 可选增值 | N17/N18 | 经验证值得投入的新场景 | 研究未通过不得进入主队列 |

不得将 L2/L3 全部做完作为修复开机启动的前提；也不得为做新功能搁置已证实的权限和保真问题。

### 7.2 最小依赖

- N01 依赖 C05 生命周期合同、C12 内存边界；N04 依赖 C04 的字符保真。
- N02 独立修正输入合同；无需等待安装器或整体 UI 重构。
- N03 依赖截图坐标/捕获验证和网络权限；N06 依赖安全持久化和 Core 术语链。
- N07/N08 依赖 C02 存储错误状态；N12 依赖配置版本与自启状态，不能与之各自维护一套真相。
- N15 语料规格可先完成；真实模型执行等待合适的测试服务授权。N17 等 N10 完成后再立项。

### 7.3 未来每个任务必须拆四个小包

1. `ID.a 合同`：定义用户动作、默认值、状态、数据与测试输入；找出当前代码对应点。
2. `ID.b 行为`：只改状态与服务逻辑，补能检出旧错误的行为测试。
3. `ID.c 界面`：接入 UI、键盘、文案、空/错误/长内容矩阵。
4. `ID.d 验收`：当前 commit/diff 的证据、真机限制、未完成项；交独立复核。

纯文案和低风险布局调整不要求虚构一个“旧反例单测”，使用实际渲染/人工检查。存储、网络、取消、输入竞争必须有行为测试。最终集成再跑全套，避免每改一句文案都重跑整仓测试。

### 7.4 后续实施模型的启动提示词模板

```text
只有在用户明确授权实施后使用本模板。
阅读 MASTER-PRODUCT-REVIEW-AND-EXECUTION-PLAN.md 和 PRODUCT-EXPANSION-REVIEW-V2.md。
本次仅领取任务 <ID> 的子包 <a/b/c/d>，先核查当前代码与现有修改。
依据第二轮合同处理冲突，不能把规划要求当作当前已具备的能力。
先给出对应入口、状态表、验收输入，再做该子包改动；不得扩大功能范围。
完成后记录：改动、实际命令/结果、证据、未验证项、下一入口。
遇到环境阻塞，记录并推进不依赖它的已授权工作；不可绕过门禁或自行标记完成。
```

“24 小时接力”表示未来执行时持续维护检查点，不表示本轮已经启动自动化或其他模型。任务没有实施授权时，停留在文档和设计范围。

## 8. 验收场景补全

| 旅程 | 最小步骤 | 通过条件 |
|---|---|---|
| 首次无服务 | 打开→填文本→去配置→返回 | 草稿仍在；不伪造翻译；拒绝联网后无发送 |
| 中文输入 | 组词→Enter 候选→再次提交 | 首次 Enter 请求 0；提交请求 1 |
| 误关恢复 | 翻译中点 X→恢复 | partial 可见、来源不变、没有自动重试 |
| 一边阅读一边生成 | 向上滚动并选择→完成 | 不跳底、不清选区、尾字不丢 |
| 快速切换 | A 请求→改文本提交 B→A 晚到 | 界面只接收 B；A 不写错误会话的历史 |
| 截图校对 | 误选→调整→OCR 修字→翻译 | 发送的是校对文本；图片未获授权时不发送 |
| 术语应用 | 收藏词→启用规则→匹配翻译 | 收藏不自动启用；只发送匹配规则；可追踪版本 |
| 写盘失败 | 收藏/保存→模拟失败→恢复权限重试 | 不假成功；旧数据保持；重试不重复写 |
| 历史关闭 | 关闭历史→翻译→隐藏恢复→退出 | 内存暂存可用；磁盘不新增历史或草稿 |
| 导入失败 | 超限/损坏备份→预检→取消 | 现有数据 hash 不变；秘密和权限不自动导入 |
| Windows 禁用自启 | 在系统禁用→手动开应用 | 显示实际状态；不偷偷重新开启 |
| 睡眠/拔屏 | 隐藏→睡眠→恢复→显示器移除→唤起 | 窗口在工作区、无焦点死锁、无重复注册 |
| 恢复性能 | 关闭隐藏前后反复唤起 | 同机记录 P95/page faults；不能仅报 WS 降低 |

每个 E3 项未来记录应用构建、操作系统、显示配置、输入法、前置状态、实际结果及证据路径。未运行保持未验证；第一轮通过的某个合成 CSV 不能外推所有导入导出都正确。

## 10. 主题配色与 UI 专项复审

### 10.1 设计结论

继续采用中性底色、克制蓝紫强调的方向。当前最需要改善的是颜色的角色、阅读层级、状态辨识以及空间分配。颜色替换必须与组件和布局一起验收；换一套 HEX 不代表产品体验变好。

主题应让用户一眼辨认：哪里可以输入、哪里是结果、当前选中了什么、哪个动作最重要、什么尚未保存。阅读区域应安静，设置区域应清晰，错误区域应给出下一步。大块留白不是自动的缺陷，但留白与拥挤同时存在、核心内容因此变窄就需要调整。

### 10.3 调色盘合同

以下读取自当前实现，作为保留方向与复核基线，**不是本轮新设计已通过对比度验收**。以后调整任一值必须验证所有实际使用背景和状态，不得只验证白底/黑底。

| 语义 token | 浅色基线 | 深色基线 | 应用原则 |
|---|---|---|---|
| Canvas | `#F6F7F9` | `#101216` | 窗口底层，不能用来区分操作状态 |
| Sidebar | `#FAFAFC` | `#14171E` | 导航背景，弱于内容；选中项另用专用状态 |
| Surface | `#FFFFFF` | `#181B22` | 主要输入/阅读面；不对每个段落重复套卡片 |
| SurfaceRaised | `#FFFFFF` | `#20242E` | 菜单和弹层；浅色靠边界/层次识别，不只靠底色 |
| TextPrimary | `#15171C` | `#EEF0F4` | 原文、译文、主要标签 |
| TextSecondary | `#4D545F` | `#A8B0BD` | 解释、字段说明，不通过随意 opacity 降低 |
| TextTertiary | `#656F7C` | `#939BAA` | 时间、附属信息；不能代替重要错误原因 |
| Primary / Text | `#5260B5` / `#FFFFFF` | `#5562B3` / `#F7F8FC` | 当前上下文的唯一主要提交动作 |
| Accent | `#5563B8` | `#7C89D9` | 链接、选中标记；不等于在线或成功 |
| BorderSubtle | `#E2E5E9` | `#2D3342` | 装饰分隔，不承担唯一控件识别责任 |
| BorderStrong | `#8590A0` | `#6B768D` | 必要的输入边界；避免所有容器都用强边框 |
| Focus | `#5260B5` | `#7C89D9` | 键盘焦点，位置/外框要区别于选中背景 |

补足以下语义角色，优先复用现有值，确有不同角色才新增 token：文本选择前景/背景、当前导航背景、代码背景/边界、错误说明、待保存提示、链接、禁用边界、阴影。禁止每个页面自行定义另一套蓝紫色。

颜色关系要求：

- 普通可读文字项目门槛≥4.5:1；关键图标、必要控件边界与焦点项目门槛≥3:1。这里是产品验收门槛，不表示已经获得无障碍合规认证。
- 检查 hover、pressed、selected、focused、disabled 与叠加状态的最终合成结果。禁用态不套用普通文本门槛硬判，但仍要求名称可辨，禁用原因用正常可读说明呈现。
- 成功=成功图标+文案；警告=提醒图标+文案；错误=错误图标+可操作说明。红绿识别不是操作前提。
- 固定、收藏、默认服务和“健康”是不同语义；默认服务不能用绿色伪装检测成功。
- 高对比模式优先采用系统颜色，减少阴影和装饰；品牌色不覆盖系统可读性需求。固定深/浅模式也必须定义高对比优先级。
- 深色不能只是全黑背景加纯白字；浅色不能靠浅灰小字堆出层级。层级通过字号、字重、位置和间距共同建立。

## 11. 排版、尺寸与布局规范

### 11.1 排版与组件尺寸（设计目标，尚待渲染验证）

| 元素 | 目标 | 约束 |
|---|---|---|
| 翻译正文 | 15 DIP 默认，行高约 1.5–1.65 倍 | 可调字号；长文保持自然断行，不把代码套自然语言排版 |
| 常规操作/表单标签 | 13–14 DIP | 关键动作不使用 10/11 DIP 小字 |
| 页面标题 | 18–20 DIP、半粗 | 小浮窗不放大标题；避免每块卡片都是 H1 |
| 辅助说明 | 12–13 DIP | 足够对比，不以字号缩小解决长文案 |
| 常规按钮/输入框 | 32–36 DIP 高 | 行内文字不被固定高裁切；字体放大时允许增高 |
| 浮窗图标按钮 | 点击区至少 32×32 DIP | 图形 16–18 DIP 左右，关闭与相邻按钮留至少 8 DIP 间隔 |
| 密集桌面图标 | 优先 16/20/24 DIP 三档 | 统一笔画和视觉重量，不用宽度相同但大小感不同的混合图标 |
| 间距 | 4/8/12/16/24/32 DIP | 相同层级统一；例外要说明用途，不无限增加魔法数 |
| 圆角 | 控件 4–6、内容容器 6–8、独立浮层约 10–12 DIP | 嵌套容器减少圆角/边框；窗口圆角与 DWM 一致 |

WPF 字体回退按实际 FontFamily 机制实现并在中文/英文机器验证，不能直接把 CSS 的 `sans-serif` 列表当成已生效字体合同。等宽字体只用于代码、必要 ID 和快捷键，长技术错误仍需可换行。

### 11.2 宽度和高度分别响应

主窗口沿用 N14 宽度规则，但断点以可用内容宽度而非截图像素判断。设置窗口内容不足容纳两列时改单列；侧栏可压缩为带名称的折叠导航。不得只把 MinWidth 从 820 改成 560 而不调整内部表单。

低高度时优先保留标题、关闭、当前主要操作和内容滚动；顶部大留白、装饰说明先压缩。底部 sticky 保存区应占独立布局行，不能覆盖表单最后一项。长错误和字体放大时按钮允许换行而不是移出窗口。

水平缩放时，正文区域优先获得新增空间；大显示器上设置表单应限制合理阅读宽度，额外空间留在外侧，不把标签与开关拉到相距一米。没有内容的空态可留白，但主要说明和操作应形成清晰整体。

## 13. 控件状态合同与误触控制

| 控件 | 默认/悬停/按下 | 选中/焦点 | 禁用/忙碌/失败 |
|---|---|---|---|
| 主按钮 | 文案稳定，hover/pressed 不改变尺寸 | 外部焦点轮廓，不用变大动画 | 忙碌替换为稳定宽度进度与取消；不连续提交 |
| 次要按钮 | 中性背景或边界，避免抢主按钮颜色 | 焦点明确 | 禁用理由在附近或可访问说明中，不依赖禁用控件 tooltip |
| 开关 | 圆点位置+轨道共同表意 | on=右、off=左；焦点环独立 | 保存中不能显示最终成功状态；失败回滚并解释；测试稳定动画末态 |
| 单选/复选 | 点击整行标签有效但避开帮助链接 | 单选表示互斥、复选表示独立 | 不为互斥选项使用一组开关；部分选中仅用于真实多选 |
| 下拉选择 | 控件宽度有下限，长项可查看完整值 | 键盘打开、方向键、Enter、Esc | 打开不得触发窗口失焦销毁；禁用保持当前值可读 |
| 输入框 | placeholder 只给示例，永久标签仍在 | 焦点边界或光标可识别 | 错误在字段旁说明，不只用红框；busy 不清文本 |
| 导航/列表 | hover 不等于 selected | 选中背景+标记+字重，键盘焦点可同时存在 | 刷新不跳到第一项；筛选保留存在的选中 id |
| 收藏/固定 | 图标轮廓与填充或文字共同反馈 | 选中持续可见 | 写盘成功后收藏才点亮；固定仅会话状态，不能伪装保存成功 |

交互细节：图标 tooltip 使用“动作 + 当前快捷键”，不要写抽象名词；快捷键修改后同步更新。焦点移动不能自动执行翻译。危险“删除/清空”与“复制/保存”不并排紧挨；双击清空造成的连续确认风险要按真实输入序列测试。

动效使用短暂颜色/透明变化辅助反馈，不移动正文、不持续闪烁、不在流式期间重复整块淡入。减少动画偏好应生效；动画结束前后的布局不变。执行模型不能通过延长动画隐藏卡顿。

上述为未来实施拆分，当前均为规划状态。颜色和布局相关改动最终统一到 `ThemeService`、`Controls.xaml`、`DESIGN_SYSTEM.md`；窗口只引用语义样式，避免每窗修出一套不同组件。

## 15. 视觉与可用性验收门槛

每个主要页面至少覆盖空态、正常、长内容、错误；翻译页面再覆盖 streaming/partial，设置页再覆盖 dirty/saving/save-failed。每个共享交互控件覆盖 default/hover/pressed/focus/selected/disabled，组合状态至少测 selected+focus、error+focus。

自动化覆盖固定虚构输入、控件布局边界、最终有效颜色、token 使用、可访问名称；人工检查阅读层级、图标清晰度、视觉拥挤、动作可发现性。两类证据不能互相替代。

最低检查集：

1. 所有页面浅/深主题各一套正常与关键失败画面，截图记录 DIP、像素、缩放、fixture、构建和时间。
2. 主窗/设置/浮窗分别测最小有效工作区与典型桌面，125/150/200% DPI；文本放大 200% 单独验证，不当作 DPI 测试替代。
3. 同一批已打开窗口和已有译文深→浅→系统往返，所有背景、文字、选择、代码、菜单、tooltip 保持一致；不通过重启规避旧资源引用。
4. 开关等待动画结束，前景与位置一致；高对比和减少动画模式另测。
5. 整条旅程键盘可完成；焦点不丢失、不被遮挡；屏幕外无关闭/保存按钮；长行可读且可复制。
6. 对每个 U01–U12 分别写通过/不通过/未验证。任何“关键操作不可达、结果读不清、控件状态误导、焦点导致丢内容”失败均阻断对应功能上线。

产品评审不能仅给美观分数：至少让 3 位未参与实现的试用者完成“第一次翻译、恢复误关结果、改目标语言、配置服务、找回历史”任务，记录是否需要提示、失败位置、误点和放弃原因。样本仅作形成性改进，不声称统计代表性；实际结果由后续试用填写。
