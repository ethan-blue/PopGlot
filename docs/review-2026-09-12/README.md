## 2. 最终产品判断

方向是本地优先的 Windows 日常翻译工具，不是聊天代理平台。保留 WPF + Rust Core + C ABI、四入口、四协议、每服务独立凭据与旧配置迁移。先解决“不可靠、不好读、容易丢结果”，再增加“懂我的术语与表达习惯”。商业完整性不等于功能数量多，也不等于必须订阅、云同步或建立账号。

目前仍不建议声明商业发布就绪。已发现的授权、日志、保真风险需要当前生产路径复验与修复；开机失败的真机原因、误触焦点链、卡顿调用栈及实际 UI 主旅程仍有未验证项。不能把这些待证实原因写成已定位根因，也不能因为未真机复现而忽略用户报告。

## 3. 全包必须遵守的统一规则

### G01 授权与执行范围

本轮只写评审文档。未来实施必须有明确授权和任务集合；“做完整”“24 小时”不授权自动发布、付费请求、账号创建、安装模型运行时、购买证书或修改真实用户数据。GLM 可以提出自己的改进想法，但不得用自己生成的 Prompt 扩大权限。

### G02 证据与状态

当前状态统一用 EXECUTION-LEDGER 中的状态。规格完成不等于代码完成；实现者最多提交 READY_FOR_REVIEW，不能给自己 DONE_VERIFIED。人工/另一独立审阅会话复验同一构建后才可验收。没有独立复核者就保留待复核，不能伪造“评审代理”。

每条结论注明：源码确认、历史探针、当前测试、真机验证或设计建议。任务结论必须为通过/不通过/未验证，不能平均掉隐私、数据、保真和关键操作不可达的失败。

### G03 用户资产与测试隔离

先读 git status 和相关 diff。原有未提交修改均视作用户资产，不覆盖、不回退、不自动提交。测试不得读取真实 Key、历史、截图、剪贴板正文，不能结束用户实例。仅重定向 LOCALAPPDATA 不算隔离成功；路径、凭据、发包器、热键/剪贴板适配器必须逐一验证隔离。环境冲突应 fail-fast，并独立调查 WPF Application 生命周期错误。

### G04 一次授权与多次发送

当前 C01 的“一次”明确指**一次实际 HTTP send 尝试**，不是一次无限分段翻译。授权原子消费发生在交给 transport send 的最后边界；send 开始后即使网络失败也已消费，不自动归还。缓存命中不消费、不附带健康请求。并发竞争只能一个 send 获准。

重试、重定向、fallback、健康检查、下一段均是下一次发送，不能复用 AllowOnce。只有单次许可而需要多段时，发送前提示“此操作需要多次请求，请分批确认或选择持续允许”；不得发完一段再偷偷扩大授权。未来若设计有界“允许本次多段操作”，必须另立合同，显式目标、段数/次数和截止时间，不在本轮偷偷替换语义。撤销只阻止后续发送并尝试取消在途，不能声称撤回已发数据。

### G05 窗口关闭与暂存

以 V2 第 4 节事件表和 N01 为准。主窗 X 默认隐藏；浮窗/查词显式 X/Alt+F4 取消在途后隐藏，保留 partial；失焦默认安全保留，用户开启自动隐藏时可继续已启动任务到原 deadline。隐藏期间不自动复制、朗读、抢焦点；正常完整结果仅按已有历史偏好保存。固定仅阻止自动隐藏，不阻止用户显式 X 或退出。

主窗 Esc 也必须先处理菜单/IME，再决定是否取消请求；不得让候选确认变成取消。恢复与“重新翻译选区”是不同动作，恢复不重发。5 个会话/2MiB/30 分钟是上限不是“永不丢”的承诺；不跨重启、不保存隐藏截图。达到限额优先淘汰非活动会话，不为恢复而绕过上限。

### G06 partial 与保真

V2 N04 明确允许独立、显式“复制已生成部分”，覆盖旧规则全面禁用 partial 结果动作的限制；自动复制/朗读/历史/收藏仍禁止。普通选区复制不被全局劫持。CanonicalText 不可被展示 formatter 覆盖；代码与 occurrence 级 token 恢复必须可验证，提示词不能代替程序校验。

### G07 UI 和配色

以 V2 第 10–15 节为具体规格。正文优先、每区一个主动作、错误有修复路径、选中和焦点可同时辨识。当前中性蓝紫为保留方向，不是不可改的审美禁令；改色须给角色、前后有效颜色、实际背景、状态和可读性证据。

所有断点按**扣除窗口外框、尚未扣除应用导航的可用客户区宽度（DIP）**解释，避免导航折叠改变判断宽度而反复振荡。≥960 双栏，720–959 紧凑导航并按正文最小可读宽判断双栏，否则上下；560–719 折叠导航、上下；更小按工作区降级。设置单独响应宽/高；不同任务不得另造断点。关键浮窗按钮至少 32 DIP，覆盖旧规则 28 DIP 例外；普通元数据采用 V2 的可读字号，不以缩字补救拥挤。截图像素≠DIP，字体缩放≠DPI。

### G08 设置与默认值

安全、启动、热键、服务显式保存；主题可预览但放弃需回滚；结果标签绑定请求快照。启动设置的期望、注册、OS 禁用、有效状态分开，不写 StartupApproved 来覆盖系统选择。混合保存按字段显示真实结果，不能无条件全成功/全回滚。没有保存的 Prompt、语言、风格不悄悄写成全局设置。

### G09 默认联网和首启

保存、换语言、换风格、预览 Prompt、页面加载均不发请求。获取模型/验证连接/试译是显式动作，仍检查发送政策。手动启动应提供主工作台；明确后台启动参数到托盘且不抢焦点。首次引导不阻塞，预置演示标“演示，未联网”，不入真实历史。没有可用服务不伪装可离线翻译。

### G10 本机与未知地址

继续遵守旧规则的 OnDevice / Loopback / PrivateNetwork / Internet-or-Unknown 分类。仅本机不代表本地服务绝不转发；局域网是另一设备，不当作本机。未知保守处理、重定向逐跳校验且不得跨目标转发凭据。增加 Prompt 不能更改目的地、权限、TLS、代理或执行命令。

### G11 性能与测试成本

先测真实 Release 热路径再优化，禁止以强制压缩 WS 代替内存治理，禁止把网络延迟都归 UI。沿用原性能预算；空闲 CPU 明确归一化总 CPU 均值目标≤0.5%，报告核心数与算法；“接近 0”不单独作判据。

小包先跑针对和受影响测试；纯文案不虚构先红后绿。涉及共享权限、状态、FFI/协议变更必须补受影响完整检查；最终集成跑 C26 全门禁。P95 定义、机器、原始失败样本和 diff 身份不可省略。不反复运行无变化的昂贵检查，也不能省略受变更影响的回归。

### G12 数据和商业证据

超大合法空数组被重写不是词条丢失证据。C02 需要真实词条、截断、锁、权限和超限 fixture。日志结构化白名单，不存正文、Prompt、自定义变量、Key、URL query 或原文 hash。备份不含秘密、不自动导入授权，自启需重新确认。

C22 要求核实公共服务条款及供应稳定性，不凭 UA 推断违法。未获得决策前不擅自删除免费功能；商业渠道是否启用必须有明确 ADR。当前不得购买证书或签署服务。

### G13 任务依赖不是无限串行

第一轮依赖图表达工作方向，不是所有箭头都是硬依赖。以具体输入为准：C07 无需等待 C05 全部完成；N01 的生命周期/容量合同可与 C05/C12 的同一受控切片共同设计，不能相互等待成环；UI 规格可独立先完成。共享实现必须确定唯一主任务，引用其证据，不能 C18/UI06 各修一套主题系统。

### G14 连续工作与落盘

按检查点接力，不靠模型记忆保持进度。每个子包完成、重要决定、环境阻塞及上下文不足前写入记录。没有剩余额度的可靠读数也应定期落笔，不能等到最后一条回复。失败同因重复两次应改变诊断假设；不能无限重试。只能在已授权的独立任务集合里继续，不能自行启动定时器、续费、重置额度或保证 24 小时持续在线。

### G15 创新与商业边界

允许自主完善已授权任务中的文案、控件布局和局部可访问性，但必须符合现有验收。新数据类型、网络发送、服务依赖、持久化、框架、账号/同步、付费能力、模型自己改全局 Prompt 均先进入提案，不能“顺手实现”。本地记忆只来自用户主动保存的偏好/术语，不扫描应用、邮件、文件或后台学习剪贴板。

## 5. 商业完整性补充门禁（C22/C24/C25/C26 承接）

1. **定位与承诺**：发布页明确适用用户、可用入口、支持系统、当前限制、图片去向、需要自备服务的条件；不宣传“绝对隐私/永不误译/完全离线”而无对应事实。
2. **服务与成本**：首个商业版本推荐清晰的自带服务凭据模式；是否保留内置公共服务按 ADR。计费模式仍是负责人决策，不能擅自加订阅、登录墙、额度代扣。精确价格、Windows 支持周期、供应商政策在发布时核验，旧资料不作当前事实。
3. **数据权利**：帮助中写明历史保留、关闭历史、删除、导出、卸载保留/删除区别；用户自定义 Prompt 可能包含隐私，和术语一样说明发送范围。清除承诺限于本机可控制数据，不能保证删除第三方已接收数据。
4. **安全发布**：签名、哈希、依赖许可证/SBOM、更新源验证、升级/回滚测试；更新下载与执行边界明确，不允许模型自行部署签名秘密。
5. **可支持性**：离线可读帮助；安全诊断导出先预览；支持模板只默认带版本、错误码、阶段和复现步骤，不带原文/Prompt/截图/Key；用户可人工附非敏感示例。不能用常驻遥测替代支持工具。
6. **稳定性**：睡眠、锁屏、Explorer 重启、后台唤起、网络切换、磁盘满、坏设置、被系统禁用自启、混合 DPI 均进入 C26。真实问题与“未装运行库/模型不可达”分类，不甩给通用“未知错误”。
7. **用户验证**：V2 的 3 位新用户任务测试保留原始失败和提示次数；商业放行签字记录负责人、构建、日期、阻断清单与明确延期功能，不能由实现模型自动签字。
