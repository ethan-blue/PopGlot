# PopGlot 隐私说明（开发阶段）

## 默认行为

- 无 API Key 时应用正常启动并使用内置免费网页引擎；模型 Provider 在缺少凭据时于构造 HTTP 前返回错误。
- 配置保存、托盘和打开设置不触发任何翻译请求。
- 只有用户主动触发划词、截图或在翻译页按下回车后，内容才会离开本机。
- 安全离线模式是总开关。开启后包括内置免费引擎在内的一切外发请求都被拒绝——这一点在 Shell 与 Core 两侧都有拦截，因为免费引擎是 Shell 侧的 HTTP 调用，Core 看不到它。

## 何时可能联网

模型请求必须同时满足安全离线模式已关闭、网络许可已打开、模型与 Key 已配置：

- 划词把用户主动选中的文本发送给文本模型。读取使用短暂剪贴板事务，随后恢复原内容。
- `LocalOcr` 的产品契约是永不上传图片；识别完全在本机 Windows OCR 引擎中完成。
- `VisionDirect` 只有在用户允许图片上传时发送编码截图。
- `Auto` 的图片上传仍需单独授权；Windows Shell 的统一 `ResolvedRoute` 同时驱动实际执行与设置页预览，避免两处规则漂移。自动模式有可用 OCR 时固定本地优先；没有 OCR 时才考虑已就绪且获授权的视觉线路。
- 视觉失败只能回退到本地 OCR + 文本，不能在用户强制本地模式时反向上传图片。
- 本地 OCR 得到的文字仍会按上述规则发送给文本模型翻译；若要完全离线，请开启安全离线模式。
- 每次会话按实际越界行为记录 `OutboundOccurred` 与 `ImageUploaded`。视觉调用一旦跨过 provider 调用边界，即使随后收到 HTTP 错误，也按可能已经发送图片保守记录；仅仅计划走视觉线路不会记为已上传。
- 性能记录拆分为取词、OCR、路由、网络/模型与总耗时；截图位图、正文和凭据不进入这些诊断字段。

内置免费网页引擎会把待翻译文本发送给 Google 的公开翻译端点（translate.googleapis.com）。它是零配置回退路径，不发送截图，也不发送任何凭据。首次使用时会弹出明确询问：允许（记住）、仅本次、或拒绝；拒绝后不会自动改用其他在线服务，也不会再出网。选择保存在 `windows-shell.json` 的 `FreeEngineConsent` 字段，可随时在「翻译服务」设置中更改。安全离线模式或网络翻译关闭时，免费引擎同样不会发出任何请求。

## 数据与日志

API Key 由 Windows Credential Manager 保存，不写普通配置、日志或 Git。Provider 日志只允许请求 ID、协议类型、endpoint、尝试次数、状态码、耗时和是否含图片；不得记录 Key、鉴权头、请求正文、图片或完整原文。上游错误正文只做有界读取以释放连接，不写日志也不回显；用户看到的是本地分类后的状态与操作建议。

图片、请求正文和响应都设有硬上限，不建立无界缓存。HTTP 请求受总超时和取消令牌控制，瞬时错误最多重试一次。

本地历史保存于 `%LOCALAPPDATA%\PopGlot\history.json`，最多 200 条、90 天、4 MiB；疑似 API Key、私钥、密码与 token 字段、超过 4,000 字符的原文或超过 8,000 字符的译文不会记录。用户可在设置中关闭、搜索、逐条删除或整体清空。截图位图永不进入历史，只有识别出的文字会被保存。

剪贴板事务不会无条件回写：仅当最新序列号仍是 PopGlot 模拟复制产生的版本时恢复原快照；若用户随后复制了新内容，新内容优先。无法安全快照的自定义格式会在模拟复制前拒绝本次划词。
