# PopGlot 隐私说明（开发阶段）

## 默认行为

- 初始配置关闭模型网络，并开启 Safe Dev Mode。
- 无 API Key 时应用正常启动，Provider 在构造 HTTP 前返回错误。
- 配置保存、托盘和打开设置不触发模型请求。
- 只有用户主动触发划词或截图会话后，内容才可能进入已配置 Provider。

## 何时可能联网

模型请求必须同时满足网络许可已打开、Safe Dev Mode 已关闭、模型与 Key 已配置：

- 划词把用户主动选中的文本发送给文本模型。读取使用短暂剪贴板事务，随后恢复原内容。
- `LocalOcr` 的产品契约是永不上传图片；当前本地 OCR 未实现，会明确失败。
- `VisionDirect` 只有在用户允许图片上传时发送编码截图。
- `Auto` 的图片上传仍需单独授权，并显示路由原因；未授权时安全回退本地 OCR。
- 视觉失败只能回退到本地 OCR + 文本，不能在用户强制本地模式时反向上传图片。

## 数据与日志

API Key 由 Windows Credential Manager 保存，不写普通配置、日志或 Git。Provider 日志只允许请求 ID、协议类型、endpoint、尝试次数、状态码、耗时和是否含图片；不得记录 Key、鉴权头、请求正文、图片或完整原文。上游错误正文只做有界读取以释放连接，不写日志也不回显；用户看到的是本地分类后的状态与操作建议。

图片、请求正文和响应都设有硬上限，不建立无界缓存。HTTP 请求受总超时和取消令牌控制，瞬时错误最多重试一次。

本地历史默认关闭。开启后保存于 `%LOCALAPPDATA%\PopGlot\history.json`，最多 100 条、90 天、2 MiB；疑似 API Key、私钥、密码字段、超过 4,000 字符的原文或超过 8,000 字符的译文不会记录。用户可在设置中手动清除。截图位图永不进入历史。

剪贴板事务不会无条件回写：仅当最新序列号仍是 PopGlot 模拟复制产生的版本时恢复原快照；若用户随后复制了新内容，新内容优先。无法安全快照的自定义格式会在模拟复制前拒绝本次划词。
