# PopGlot 隐私说明（开发阶段）

## 默认行为

- 初始配置关闭模型网络，并开启 Safe Dev Mode。
- 无 API Key 时应用正常启动，Provider 在构造 HTTP 前返回错误。
- 当前截图选区只进入本地演示流程，没有接入真实位图上传。
- 配置保存、预览、托盘和快捷键操作不触发模型请求。

## 何时可能联网

当前版本只有用户主动点击“测试连接”才会调用 Provider，并且必须同时满足：网络许可已打开、Safe Dev Mode 已关闭、文本模型与 Key 已配置。请求只包含内置的连接测试文本，不包含截图、剪贴板或用户原文。

未来接入翻译流程后：

- `LocalOcr` 永不上传图片，只把本地 OCR 后的文本交给文本模型。
- `VisionDirect` 只有在用户允许图片上传时发送编码截图。
- `Auto` 的图片上传仍需单独授权，并显示路由原因；未授权时安全回退本地 OCR。
- 视觉失败只能回退到本地 OCR + 文本，不能在用户强制本地模式时反向上传图片。

## 数据与日志

API Key 由 Windows Credential Manager 保存，不写普通配置、日志或 Git。Provider 日志只允许请求 ID、协议类型、endpoint、尝试次数、状态码、耗时和是否含图片；不得记录 Key、鉴权头、请求正文、图片或完整原文。上游错误正文只做有界读取以释放连接，不写日志也不回显；用户看到的是本地分类后的状态与操作建议。

图片、请求正文和响应都设有硬上限，不建立无界缓存。HTTP 请求受总超时和取消令牌控制，瞬时错误最多重试一次。历史记录尚未实现；未来默认关闭且截图默认不落盘。
