## 一、确认并修复的缺陷

1. **极速查词授权不一致**：旧配置 `Unset` 被自动翻译入口拒绝，而手动入口允许。统一为仅 `Denied` 拒绝。
2. **Auto 冷却触发全局降级**：线路全部冷却的业务异常可逃逸 DispatcherTimer，令全局快捷键一起停用。现在转为窗口内恢复提示。
3. **隐藏后幽灵请求**：输入后在 debounce 到期前 Esc/X/Alt+F4/Hide，旧 Timer 仍可发送。统一撤销待执行任务，过期 Tick 及重开均不能复活。
4. **原文译文错配**：修改输入后、debounce 前仍可收藏或转交旧译文。现在编辑立即失效结果动作，持久化携带结果原始身份，工作台转交使用 App 持有的主窗口。
5. **虚假恢复文案**：有道长句提示按 Enter，但 Enter 同样无法处理。去掉该承诺。
6. **设置长页面**：公共翻译、自定义 JSON API、AI 与账号独立分页；AI 详情再分连接、模型、高级与性能。滚轮跟随当前页，模型下拉框测试必须先打开模型页。
7. **系统代理 DIRECT/null 被改写**：现代系统代理可能 `IsBypassed=false`、`GetProxy=null` 表示直连。旧代码把 null 改成目标地址，造成向翻译服务器自身发 CONNECT。保持 null 后，Google / MyMemory 的系统代理路径恢复真实有效译文。
8. **Google 备用接口响应变化**：兼容 `clients5` 的平铺字符串数组，不再只接受嵌套数组。
9. **长文过度分段**：Google 较长内容在 5000 字符范围内使用同提供方表单 POST，不再因 GET URL 预算切成几十次串行请求；保留 GET 的本地 URL 限制。MyMemory 等仍按真实单次限制有序分段。
10. **Auto 分段接收方不稳定**：先按完整输入确定提供方，再按实际提供方预算规划，并在授权快照中冻结接收方；设置改变不能把后续片段悄悄发送给另一家。
11. **预热无效和空闲读盘**：预热与正式发送共用同一 HttpClient/连接池；生产窗口设置更新走持久化事件而非每 100ms 轮询文件，隐藏时解除订阅。
12. **错误与超时边界**：30 秒预算覆盖响应体读取；连接错误不回显携带原文的 URL；TLS 证书错误作为不可重试的配置错误，保留校验，不盲目重复请求。

## 二、自定义传统翻译 API

新增 `CustomTranslationApi` 与独立编辑器，支持：
- 自定义完整 HTTPS JSON POST 地址，或本机回环 HTTP。
- JSON 请求模板、完整/基础/大写语言代码及 JSON Pointer 译文字段，提供 LibreTranslate / DeepLX 模板。
- 可选密钥请求头、前缀及请求体占位符。密钥进入 Windows Credential Manager，按地址绑定，不把旧地址密钥自动送给新地址。
- 单遍 JSON 字符串替换，原文即使包含 `{apiKey}` 也不能触发二次展开。
- 非空字符串译文验证、4 MiB 响应上限、取消、出网逐次再授权，不跟随重定向，不耗用公共线路本机 400/h 配额。
- 默认不自动调用可能收费的自定义 API；须显式选择“所有引擎”。

**边界**：这不是任意签名协议解释器；百度/腾讯等动态签名官方接口需要专用适配器。模板参数和服务语言支持以实际服务为准。
