# 快捷键全景与冲突排查 (Keyboard Shortcuts)

快捷键是 PopGlot 极速翻译体验的核心。本文档基于当前代码事实（`ShellSettings` 与 `HotkeyService`）列出所有默认按键绑定、窗口内局部操作及按键冲突解决办法。

---

## 全局快捷键真实值表 (System-Wide Hotkeys)

无论您当前正在使用哪个应用程序（IDE、浏览器、终端、阅读器等），以下全局快捷键随时生效：

| 功能名称 | 默认按键绑定 | 内部标识 | 作用与交互说明 | 可否自定义 |
|---|---|---|---|:---:|
| **划词翻译** | `Ctrl + Alt + W` | `TranslateSelection` | 选中屏幕上的文字后按下，呼出贴近光标的流式结果浮窗 | **是** |
| **截图翻译** | `Ctrl + Alt + Space` | `CaptureScreen` | 呼出全屏截图选区遮罩，框选任意区域后松开自动识别并翻译 | **是** |
| **截图提取文本 (OCR)** | `Shift + 截图` | — | 触发截图后，识别文字直接存入剪贴板，不触发大模型翻译 | 随截图键联动 |
| **关闭浮窗** | `Ctrl + Alt + X` | `ClosePanel` | 强制关闭当前显示的划词或截图结果浮窗（不影响主窗口） | **是** |
| **打开主窗口** | `Ctrl + Alt + O` | `ShowWindow` | 随时在屏幕中央呼出 PopGlot 主翻译与资料库工作台 | **是** |

> **提示**：所有 4 组全局快捷键均可在「设置 → 快捷键」中点击录制框，直接按下您习惯的新按键组合进行修改。

---

## 窗口内局部快捷键 (Window Context Keybindings)

当焦点位于 PopGlot 的浮窗、极速查词栏或主工作台时，支持以下高频键盘操作：

### 1. 浮窗与极速查词栏 (`TranslationPanelWindow` / `QuickSearchWindow`)
- **`Esc` (两段式 Esc 阶梯)**：
  - **第一击**：如果当前正处于流式翻译或网络请求中，立即**取消在途网络请求**，保留已输出的片段；
  - **第二击**：当无在途请求时，**关闭浮窗或查词栏**；
- **`Ctrl + C`**：快速复制当前译文文本到系统剪贴板；
- **`Ctrl + P`**：触发或中止当前译文的语音朗读（TTS）；
- **`Enter`**：在查词输入框中提交当前输入的文本并发起翻译；
- **`方向键 ↑ / ↓`**：在查词历史建议列表中切换选中项。

### 2. 主工作台 (`TranslateSection`)
- **`Enter`**：在左侧源文本输入框中直接触发翻译；
- **`Shift + Enter`**：在输入框内换行；
- **`Alt + S`**：快速聚焦源语言下拉选择框；
- **`Alt + T`**：快速聚焦目标语言下拉选择框。

## 快捷键录制规则 (`HotkeyRecorder`)

在「设置 → 快捷键」中录制自定义组合时，系统执行以下安全性与操作系统规范验证：

1. **必须包含修饰键**：
   - 组合键必须至少包含 `Ctrl`、`Alt` 或 `Win` 中的至少一个修饰键（例如 `Ctrl+Shift+F`）；
   - 单独的字母键、数字键或功能键（如单独按 `F1` 或 `A`）**禁止注册为全局热键**，以防严重破坏系统的日常文本输入。
2. **支持复合修饰键**：
   - 支持 `Ctrl+Shift+...`、`Ctrl+Alt+Win+...` 等多重修饰键组合，充分满足无冲突自定义需求。
3. **录制交互指引**：
   - 单击快捷键文本框后进入「请按下快捷键…」高亮录制态；
   - 依次按下目标组合键并松开，录制器将自动捕获并显示友好键名；
   - 按下 `Esc` 或点击空白处可放弃本次录制，恢复原有按键。

## 快捷键冲突排查与原子恢复机制

### 1. 注册冲突时的原子回滚保护
当您保存设置时，系统会尝试向 Windows 注册全部 4 组快捷键：
- **冲突即时阻断**：若某个新组合已被其他系统软件（如微信、QQ、IDEA 或显卡驱动快捷键）占用，Windows 底层注册会返回失败；
- **原子回滚，绝不悬空**：PopGlot 会立即中止保存流程，**自动将全部快捷键恢复为上一组正常工作的有效按键**；
- **精确定位错误**：设置页底部状态栏会清晰报错并提示具体是哪一组快捷键注册失败：「快捷键注册失败，请换一个未被占用的组合。未保存任何修改。」

### 2. 常见按键冲突与推荐配置

若遇到快捷键无法注册，通常由以下后台应用占用导致：

| 冲突表现 | 常见占用者 | 建议排查与替代方案 |
|---|---|---|
| `Ctrl+Alt+W` 冲突 | 微信 Windows 客户端（默认发送/语音快捷键） | 在微信设置中取消该热键，或将 PopGlot 改为 `Ctrl+Shift+T` / `Alt+Q` |
| `Ctrl+Alt+Space` 冲突 | 某些第三方拼音输入法（全半角切换）或 macOS 映射软件 | 推荐改为 `Ctrl+Shift+A`、`Alt+X` 或 `Win+Shift+Z` |
| `Ctrl+Alt+X` 冲突 | 迅雷、下载工具或显卡控制台悬浮球 | 推荐改用 `Ctrl+Shift+Escape` 或保留默认由 `Esc` 键替代 |
| `Ctrl+Alt+O` 冲突 | 钉钉、飞书等协同软件的全局呼出键 | 推荐改为 `Ctrl+Shift+O` 或 `Win+Alt+T` |

### 3. 以管理员身份运行应用的穿透问题
依据 Windows 的安全机制（UIPI 权限隔离）：
- 如果您当前正在聚焦一个「以管理员身份运行」的窗口（如管理员权限的 PowerShell、任务管理器或特定开发工具），而 PopGlot 自身以普通用户权限运行；
- 此时全局热键可能无法读取该窗口内的文本选区；
- **解决方案**：若日常深度依赖管理员终端取词，可将 PopGlot 也设置为「以管理员身份运行」。
