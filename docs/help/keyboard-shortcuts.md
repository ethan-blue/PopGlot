# 快捷键

以下为默认组合。更改后以「设置 → 快捷键」和按钮的悬停提示为准。

## 全局快捷键

| 动作 | 默认组合 |
| --- | --- |
| 划词翻译 | `Ctrl+Alt+W` |
| 截图翻译 | `Ctrl+Alt+Space` |
| 关闭翻译浮窗 | `Ctrl+Alt+X` |
| 打开主窗口 | `Ctrl+Alt+O` |
| 极速查词 | `Ctrl+Alt+Q` |

截图时按住 Shift 松开鼠标，仅提取文字；也可从托盘菜单选择「截图提取文本（OCR）」。

## 窗口内操作

| 动作 | 默认组合 |
| --- | --- |
| 选择模型 | `Ctrl+M` |
| 选择风格 | `Ctrl+T` |
| 互换语言 | `Ctrl+L` |
| 翻译 | `Ctrl+Enter` |
| 朗读译文 | `Ctrl+P` |
| 打开设置 | `Ctrl+,` |
| 翻译工作台 | `Ctrl+1` |
| 资料库 | `Ctrl+2` |

工作台输入框中 Enter 换行，默认 Ctrl+Enter 翻译。查词输入框中 Enter 直接翻译。

- `Esc`：先关闭展开的菜单；有请求时取消并保留已收到的片段，无请求时收起浮窗。输入法正在组词时先交给输入法处理。
- `Ctrl+C`：复制选中的文字。
- `Ctrl+Shift+C`：复制译文。
- `Ctrl+R`：重试翻译。
- `Ctrl+S`：收藏已完成的译文。
- 查词窗口的上下方向键：选择历史建议。

## 修改或停用

1. 打开「设置 → 快捷键」，点击要修改的录制框。
2. 按新组合；按 Esc 放弃，按退格键停用该动作。
3. 保存。停用后仍可从按钮或托盘菜单使用相应功能。

全局组合需要修饰键。重复组合、与保留编辑键冲突的组合会在保存前提示；与其他程序的全局快捷键冲突时会尝试恢复原设置，请根据提示更换组合。

如果快捷键能呼出浮窗却读不到管理员窗口的文字，可先复制文本到主窗口，或使用截图翻译。
