# 快速上手指南 (Getting Started)

欢迎使用 PopGlot！PopGlot 专为 Windows 设计，面向需要高频阅读英文技术文档、代码注释、终端报错与系统命令的开发者和专业用户。

---

## 核心交互四入口

PopGlot 提供四大翻译与查词入口，覆盖日常工作中的各类读写场景：

### 1. 划词翻译 (`Ctrl+Alt+W`)
在任意支持文本复制的应用程序（浏览器、IDE、PDF 阅读器、办公软件等）中：
1. 鼠标选中想要翻译的一段文本或代码报错；
2. 按下默认快捷键 `Ctrl+Alt+W`；
3. 紧邻选区上方或下方将弹出一个半透明、无干扰的轻量级流式浮窗；
4. 译文内容将实时流式渲染呈现。完成后可按 `Esc` 关闭浮窗，或按 `Ctrl+Alt+X` 强制关闭。
> **剪贴板保护提示**：划词翻译采用安全剪贴板事务模拟复制；读取完成后自动恢复用户原有剪贴板快照，绝不破坏用户原本复制的内容。

### 2. 截图翻译 (`Ctrl+Alt+Space`)
当遇到无法直接选中文本的场景（如远程桌面、图片、游戏窗口、受保护的 PDF 或特定终端）：
1. 按下快捷键 `Ctrl+Alt+Space`，屏幕变暗并进入全屏高精度框选遮罩；
2. 拖拽鼠标左键框选需要识别翻译的矩形区域；
3. 松开鼠标后立即开始识别：
   - **默认本地优先**：直接调用 Windows 内置 OCR 引擎在本地完成文字识别，完全不上传截图图片；
   - 识别文字随即进入翻译流程并弹出结果浮窗；
4. **仅提取文字 (OCR-Only)**：若只需提取文字无需翻译，可在托盘菜单选择「截图提取文本 (OCR)」，或在截图时配合热键，识别后文字将直接进入剪贴板。

### 3. 主工作台输入 (主窗口)
随时按下 `Ctrl+Alt+O` 或双击托盘图标，可呼出 PopGlot 主窗口：
- **双栏交互工作台**：左侧为源文本编辑区，右侧为格式化译文与解析区；
- **智能排版与断行合并**：支持一键「合并断行」（修复从 PDF 复制时产生的混乱换行符）；
- **回车即译**：在左侧输入文本后，按下 `Enter` 立即发起翻译，按下 `Shift+Enter` 执行换行；
- **发音与收藏**：点击喇叭图标收听原文或译文语音朗读，点击五角星一键收藏至生词本。

### 4. 极速查词栏 (Quick Search)
专为单词、短语和快速命令查询设计的即时搜索栏：
- 可通过托盘右键菜单选择「极速查词」快速唤起；
- 单行搜索框居中浮现，输入即开始防抖检索，击键流畅不粘滞；
- 底部展示历史词汇匹配，按上下键选择，按 `Enter` 实时翻译，按 `Esc` 快速退出。

## 首次运行与引擎配置

PopGlot 坚持「开箱即用，尊重隐私」的设计理念。首次启动后无需复杂的配置向导：

### 1. 无可用引擎时的空态引导
若尚未配置任何大模型密钥：
- 进入主工作台或触发查词时，结果区域将显示清晰的引导卡片：**「尚未配置翻译引擎」**；
- 界面提供两个清晰的行动入口：
  - **「添加翻译引擎」**：一键直达设置窗口，连接您自己的大模型 API（如 DeepSeek、OpenAI、Claude、Gemini 或本地 Ollama）；
  - **「使用内置公共翻译」**：开启零配置公共翻译服务（详见下文）。

### 2. 内置公共翻译服务（零配置回退路径）
如果您暂时没有个人 API Key，可直接使用内置公共翻译：
- 该服务将待翻译纯文本发送至公共翻译接口；
- **显式授权机制**：首次启用前必须获得您的主动授权。默认线路发往 `translate.googleapis.com` 与 `clients5.google.com`；若这条不可用，可在引擎菜单改选备用免费引擎（`api.mymemory.translated.net`）。一次只使用选中的那一条。
- **零额外隐私泄露**：公共翻译仅发送纯文本，绝不发送您的屏幕截图、剪贴板历史或任何系统文件。

### 3. 添加您自己的大模型引擎
如果您追求更高质量的技术翻译与上下文解释：
1. 点击主窗口左下角的「设置」按钮（或托盘右键选择「设置」）；
2. 默认定位至「翻译引擎」分区，点击右上角「添加引擎」；
3. 选择预设提供商（如 DeepSeek、OpenAI、Claude、Gemini、Ollama 等）或填写兼容的 Base URL；
4. 填入您的 API Key，点击「验证连接」发送短测试请求；
5. 点击「获取模型」下拉选择文本翻译模型，点击「保存」并设为默认；
6. 后续的所有划词、截图与工作台翻译将立即使用您自己的大模型服务。

## 基础常用设置

进入「设置」窗口可进行以下个性化调节：

- **通用设置**：
  - **外观主题**：支持「跟随系统」、「浅色」、「深色」模式无缝热切换，全面支持 Windows 高对比度无障碍模式；
  - **开机自启**：勾选「开机自动启动」，系统登录后静默驻留托盘；
  - **失去焦点自动隐藏**：可配置当浮窗失去鼠标焦点时是否自动关闭；
  - **自动复制译文**：翻译完成后自动将译文写入系统剪贴板。
- **资料库管理**：
  - 左侧导航进入「资料库」，可查阅所有本地翻译历史与生词本条目，支持实时关键词过滤与鼠标自由拖拽分栏（GridSplitter）。
