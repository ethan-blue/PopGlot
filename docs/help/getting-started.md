# 快速上手

解压后运行 `PopGlot.exe`。程序驻留在任务栏通知区域；按 `Ctrl+Alt+O` 打开主窗口。

## 第一次翻译

1. 选中一段文字，按 `Ctrl+Alt+W`，在光标附近查看译文。
2. 没有配置引擎时，直接用公共翻译，也可到「设置 → 引擎 → 添加引擎」配置自己的服务。
3. 公共翻译免配置、默认开启，包含 `Google`、`Bing`、`有道词典`、`MyMemory` 和 `自动优选` 五条线路，每次只发往选中的单条线路，不发送截图。可在「设置 → 引擎 → 内置免费线路」或浮窗、查词窗口底部的线路菜单切换线路；如需彻底关闭，可在「设置 → 隐私与数据」直接关掉「公共翻译」。

划词通过模拟复制读取选区。读取后会尝试恢复原剪贴板；如果你期间复制了其他内容，以新内容为准。不能复制的文字可改用截图。

## 常用入口

| 入口 | 默认快捷键 | 用法 |
| --- | --- | --- |
| 划词翻译 | `Ctrl+Alt+W` | 选中文字后按快捷键。 |
| 截图翻译 | `Ctrl+Alt+Space` | 立即定格屏幕（悬停弹窗与菜单也会保留），框选后识别并翻译；按住 Shift 松开只提取文字。 |
| 固定区域截图翻译 | `Ctrl+Shift+G` | 首次框选固定区域，之后按快捷键直接截取同一区域翻译（适合字幕或固定提示框）。 |
| 主窗口 | `Ctrl+Alt+O` | 左侧输入原文，右侧查看译文。默认 `Ctrl+Enter` 翻译，`Enter` 换行。 |
| 极速查词 | `Ctrl+Alt+Q` | 输入单词、句子或报错，按 `Enter` 翻译（`Shift+Enter` 换行）；默认开启「边输边译」（停顿 500 ms 自动在公共翻译线路翻译，不写历史）。 |

截图默认在本机识别文字，再把文字交给所选翻译引擎。视觉识别或图片直译会发送截图，需要单独允许上传。

请求进行中按 Esc 取消，已收到的文字仍可手动复制；再次按 Esc 收起浮窗或查词窗口。`Ctrl+Alt+X` 也可关闭翻译浮窗。

## 切换模型与风格

点击窗口底部的模型按钮，选择已保存的引擎或公共翻译。在工作台有原文时，换用另一个引擎会重新翻译；翻译途中也可切换。重新选择当前引擎不会重复发送。资料库页切换引擎不发起后台翻译。

点击风格按钮选择「准确」「自然」「正式」或自定义风格；有原文时会重新翻译。公共翻译不支持风格和要点，因此隐藏这两个入口。图片直译不应用文字风格。

「要点」单独显示原文摘要，切回「译文」可继续阅读原来的翻译。

## 添加引擎

在「设置 → 引擎 → 添加引擎」选择来源：

- API：填写服务地址、API Key 和模型，按需测试后保存。本机模型地址可不填密钥。
- 本机工具：点击「检测 Codex / OMP」，选择入口，再连接账号、选择模型并保存。账号由工具管理。
- ChatGPT：通过浏览器授权，刷新模型并保存。请求使用账号可用的额度。

保存配置本身不发起翻译；获取模型、测试连接和登录是单独的联网操作。详细步骤见[配置翻译引擎](provider-setup/index.md)。

## 常用设置

- 通用：主题、开机自启、关闭到托盘、浮窗行为、查词窗口（边输边译开关、500 ms 等停顿延迟、仅公共线路或全部引擎范围、紧凑小窗/完整大窗形态）以及网络与代理（跟随系统代理、直连、自定义代理、本地与国内线路直连加速）。
- 快捷键：修改全局和窗口内快捷键；支持单按 `F1–F12` / `PrintScreen`、实时占用检测、一键改用空闲组合，点右侧 `×` 或按退格键即可停用。
- 提示词：查看内置风格，创建或编辑自己的翻译规则。
- 隐私与数据：安全离线模式、允许连接云端翻译服务、允许上传截图、云端在线朗读、公共翻译开关、截图翻译方式、本机文字识别语言包与崩溃诊断上报。

在「资料库」查看本地历史与生词本，可搜索、删除和导出。双击条目载入工作台；原文可拖选，复制原文/译文/解释与术语芯片均可用。清空当前列表需两步确认（首次点击武装「确认清空?」，再次点击才清空），撤销部分恢复时如实报告条数。未完成或取消的翻译不写入历史。

源语言为 auto 时按原文文字自动定向：中文原文自动译成英语、英文原文自动译成简体中文；手选源语言可覆盖。互换语言会把上一轮译文回填输入框并自动重译，往返方向命中缓存时直接复用上次译文。
