# 快速上手

解压后运行 `PopGlot.exe`。程序驻留在任务栏通知区域；按 `Ctrl+Alt+O` 打开主窗口。

## 第一次翻译

1. 选中一段文字，按 `Ctrl+Alt+W`，在光标附近查看译文。
2. 没有配置引擎时，直接用公共翻译，也可到「设置 → 引擎 → 添加引擎」配置自己的服务。
3. 公共翻译免配置、默认开启，不需要先去授权。Google 接收文本的地址为 `translate.googleapis.com` / `clients5.google.com`；MyMemory 为 `api.mymemory.translated.net`。每次只使用选中的服务，不发送截图。改用 MyMemory 在浮窗或查词窗口底部的线路菜单里选；要彻底关掉这一路，走「设置 → 通用 → 重新显示引导」，在向导的隐私一页取消勾选。

划词通过模拟复制读取选区。读取后会尝试恢复原剪贴板；如果你期间复制了其他内容，以新内容为准。不能复制的文字可改用截图。

## 四种入口

| 入口 | 默认快捷键 | 用法 |
| --- | --- | --- |
| 划词翻译 | `Ctrl+Alt+W` | 选中文字后按快捷键。 |
| 截图翻译 | `Ctrl+Alt+Space` | 框选区域，松开鼠标后识别并翻译。按住 Shift 松开鼠标时，只提取文字。 |
| 主窗口 | `Ctrl+Alt+O` | 左侧输入原文，右侧查看译文。默认 `Ctrl+Enter` 翻译，Enter 换行。 |
| 极速查词 | `Ctrl+Alt+Q` | 输入单词、句子或报错，按 Enter 翻译；输入本身不会提交翻译请求。 |

截图默认在本机识别文字，再把文字交给所选翻译引擎。视觉识别或图片直译会发送截图，需要单独允许上传。

请求进行中按 Esc 取消，已收到的文字仍可手动复制；再次按 Esc 收起浮窗或查词窗口。`Ctrl+Alt+X` 也可关闭翻译浮窗。

## 切换模型与风格

点击窗口底部的模型按钮，选择已保存的引擎或公共翻译。有原文时，换用另一个引擎会重新翻译；翻译途中也可切换。重新选择当前引擎不会重复发送。

点击风格按钮选择「准确」「自然」「正式」或自定义风格；有原文时会重新翻译。公共翻译不支持风格和要点，因此隐藏这两个入口。图片直译不应用文字风格。

「要点」单独显示原文摘要，切回「译文」可继续阅读原来的翻译。

## 添加引擎

在「设置 → 引擎 → 添加引擎」选择来源：

- API：填写服务地址、API Key 和模型，按需测试后保存。本机模型地址可不填密钥。
- 本机工具：点击「检测 Codex / OMP」，选择入口，再连接账号、选择模型并保存。账号由工具管理。
- ChatGPT：通过浏览器授权，刷新模型并保存。请求使用账号可用的额度。

保存配置本身不发起翻译；获取模型、测试连接和登录是单独的联网操作。详细步骤见[配置翻译引擎](provider-setup/index.md)。

## 常用设置

- 通用：主题、开机启动、关闭到托盘、自动收起浮窗、自动复制译文。
- 快捷键：修改全局和窗口内快捷键；录制时按退格键可停用某项。
- 提示词：查看内置风格，创建或编辑自己的翻译规则。
- 隐私与数据：网络许可、安全离线模式、截图上传、公共翻译状态、云端朗读和诊断上报。公共翻译默认开启，它的开关在「设置 → 通用 → 重新显示引导」的向导里。

在「资料库」查看本地历史与生词本，可搜索、删除和导出。未完成或取消的翻译不写入历史。
