# 翻译引擎配置

入口：设置 → 引擎，分为「公共翻译」「自定义 API」「AI 与账号」三个独立页面，不再把所有内容堆在同一条长页面上。底部模型菜单可直接切换。保存配置不自动测试或提交翻译。

## 公共翻译与自定义翻译 API

- 「公共翻译」可选择 Google、MyMemory、有道词典、Yandex 或自动优选。Yandex 仅手动选择，不参与自动优选；当前接口不区分中文简繁，需要繁体目标请用其他线路。Bing 为实验性：先测速，返回实际译文后才参与自动优选，令牌页成功不代表翻译可用。
- 「自定义 API」接入自建 JSON POST 翻译服务，不是 OpenAI 聊天接口。选择 LibreTranslate / DeepLX 模板，或需自备凭据的 DeepL 官方 / 彩云模板，填完整地址、请求 JSON 与译文字段，再点击「测试翻译」。测试只发送固定的 Hello world，不保存草稿。
- 请求模板支持 `{text}`、完整语言代码 `{source}` / `{target}`、去地区码 `{sourceBase}` / `{targetBase}`、大写 `{sourceUpper}` / `{targetUpper}` 与密钥 `{apiKey}`。替换按 JSON 字符串编码，不会把原文中形似占位符的内容再次展开为密钥。
- 响应路径使用 JSON Pointer，例如 `/translatedText`、`/data`、`/translations/0/text`。仅非空字符串算成功；HTTP 200 本身不算成功。
- 认证可设置密钥请求头与前缀，或在模板中使用 `{apiKey}`。地址变更不会自动继承另一地址的密钥。普通配置位于 `custom-translation-api.json`，密钥留在 Windows 凭据管理器。
- 只支持 HTTPS 或本机回环 HTTP；不自动实现百度/腾讯等动态签名，也不跟随重定向。该接口可能收费，自动翻译需明确选择「所有引擎」。

## API 或本机模型

1. 在「AI 与账号」页面点击「添加 AI 引擎」，选择服务商预设或自定义协议。编辑器分为「连接」「模型」「高级与性能」三页；地址与密钥在连接页，自定义请求头、路径与生成参数在高级页。
2. 填写地址和文字模型。在线服务需要 API Key；本机回环地址可留空。
3. 可主动获取模型、测试连接；也可直接填写实际模型 ID 后保存。普通 API 保存不以测试成功为门槛。
4. 点击编辑器底部「保存」。首个完整文字引擎可成为当前引擎；编辑已有引擎不会抢占正在使用的其他线路。

| 服务 | 协议 | 常见地址 |
| --- | --- | --- |
| OpenAI | OpenAI 兼容或 Responses | `https://api.openai.com/v1` |
| DeepSeek | OpenAI 兼容 | `https://api.deepseek.com` |
| Anthropic | Anthropic Messages | `https://api.anthropic.com` |
| Gemini | Gemini GenerateContent | `https://generativelanguage.googleapis.com` |
| Ollama | OpenAI 兼容 | `http://localhost:11434/v1` |
| LM Studio | OpenAI 兼容 | `http://localhost:1234/v1` |

模型 ID、账户权限与视觉能力以服务商的当前目录为准。自建网关使用自己的地址；不要把某个服务商的密钥填到另一地址。网络许可、局域网许可和 TLS 设置仍分别生效。

已保存的 API 引擎可以重新编辑地址、协议、模型与高级参数。修改连接参数后，旧目录和旧测试证据不再代表新配置；在旧地址上发起的模型查询不会写回新表单。

DeepL 官方模板明确使用“自动检测原文”，API Free / Pro 地址应与自己的账户匹配。彩云模板按语言方向组装参数，仅支持服务开通的方向。选择模板不联网、不保存，也不会把旧地址的密钥复制到新地址。

## 长文与思考参数

API 引擎的生成参数随该引擎保存，不需要修改密钥。上下文窗口用于估算一次请求能容纳多少原文；输出预算用于限制单次生成。留为自动时，PopGlot 使用保守上下文和按原文长度计算的输出预算，能放进预算的文章不再拆成 800 字符的小请求。

- **上下文窗口**：填写服务商公布的该模型实际容量，不是填写越大越好。输入、提示词、思考和输出都要占空间。
- **输出预算**：应给完整译文及思考留足空间，但不能超过模型自身支持的上限。它不是服务商保证一定生成的字数。
- **思考程度**：自动保持服务默认；其他级别只在支持的协议和模型上使用。高思考可能增加延迟和消耗，不保证翻译更好。

更改这些参数不会自动发起请求。请保存后测试或重新翻译；截断和连接早闭会保留已收到的部分，而不是冒充完整结果。免费公共翻译不使用这些 AI 参数，托管工具路线由其自身能力与配置决定。

## 连接本机工具

1. 在「添加引擎」页面点击「检测 Codex / OMP」，或直接点击来源目录的「oh-my-pi」/「Codex CLI」预设按钮触发同一检测。检测只检查工具入口，不启动推理，也不代表已登录。
2. 选择 oh-my-pi 或 Codex CLI，点击「连接 / 刷新账号」。这一步通过工具协议读取账号状态和模型。
3. 选择模型。OMP 如需新登录，可选择提供方并通过浏览器授权；必要时粘贴授权回调。
4. 可点击「测试翻译」，发送 `Hello world`，会使用所选模型的少量额度。
5. 可在「显示名称」填写自定义引擎名，留空使用自动名称；「保存」只保存，「保存并使用」同时切换当前文字引擎。

- 本机 CLI 不等于本地推理：文字会发送到该工具配置的提供方并使用其额度；安全离线模式会阻止这条外发路线。
- 支持原生入口，以及可解析的官方包入口；不执行 `.cmd` / `.ps1` 脚本，不从当前目录猜测同名程序。
- 重新检测在后台执行，可取消。已保存但本次未发现的入口会保留并标明状态，不会被静默删除。
- 编辑、重新连接与重新保存沿用同一条引擎记录。若原模型不在当前目录中，需要明确重新选择，不会自动改用另一个模型。
- 「断开连接」禁用 PopGlot 的该连接并取消相关请求，保留工具自己的登录；之后可重新连接。
- 删除托管引擎走两段确认：删除后列表行消失，默认引擎正确回退；删除引擎不会删除账号登录。托管引擎可在「显示名称」改名，保存后列表行显示新名。

### 将 OMP 模型改为 API 直连

连接 OMP 并选择受支持提供方的模型后，展开「将所选模型改为 API 直连」。只有明确勾选授权后，才会导入所选提供方的普通 API Key 并存入 Windows 凭据管理器；不导入 OAuth 登录记录。多个有效 Key 不自动择一，可改为手工添加 API 引擎。

## ChatGPT 官方直连

在「添加引擎」页面选择「ChatGPT」，点击「登录 ChatGPT」。授权在浏览器页面完成；返回后刷新当前账号与工作区的模型目录，选择模型，再测试或保存并使用。已登录账号下按钮显示「添加账号」，可再授权一个新账号；选中无凭据的账号时显示「重新授权」，沿用原注册。

保存的模型名称只是回显，不代表账号目前仍有权限。刷新或切换账号会清掉旧测试证据。可在「显示名称」为该引擎改名。断开引擎与删除账号是不同操作：断开保留登录；「退出账号」撤销会话并移除本机注册，「删除账号」可直接移除无凭据的死账号。可取消登录、模型刷新和测试等待；已经进入落盘提交阶段时不再显示可取消操作。

编辑态底栏提供删除、取消与保存；列表行的删除按钮对 API 与托管引擎同样走两段确认。连接测试失败时优先显示截断或错误类原因（如「输出达到长度上限」），中性提示不会冒充失败原因。

账号授权流程受官方服务与账号资格限制；隔离模拟验证不代表真实账号授权一定可用。

## 文字、截图和要点

- 文字引擎用于划词、工作台、查词和 OCR 识别后的文字翻译；视觉引擎负责获准上传的截图。
- 本地 OCR 只表示识别在本机完成，后续文字翻译是否联网取决于文字引擎。
- 安全离线模式、图片上传许可与实际截图路线可在「隐私与数据」查看；草稿会明确标为保存后生效。
- 公共翻译不支持自定义语气或整理要点。本机模型须配置自己的文字模型；在线模型还须满足当前联网许可和凭据要求。
- 在翻译工作台换用另一个引擎时，有原文就会重新翻译；正在进行的旧请求会被取消。重新选择当前引擎不重复发送。资料库页切换引擎不发起后台翻译，切回工作台再换才重译。

## 凭据与测试

API Key 按引擎存入 Windows Credential Manager，不写进普通配置或日志。未输入新 Key 不会覆盖已保存 Key。测试连接使用草稿和程序生成的短文本，不上传截图或历史；保存配置本身不联网。

模型推荐的极速、均衡、高质档位只提供建议。缺少能力证据时显示未知，不把模型名称猜测当成已验证能力。
