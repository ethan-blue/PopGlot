# 翻译引擎配置

入口：设置 → 翻译引擎。API、本机工具和 ChatGPT 直连保存到同一引擎列表；工作台底部可切换当前文字引擎。保存设置不会自动测试或提交翻译。

## API 或本机模型

1. 点击「添加引擎」，选择服务商预设或自定义协议。
2. 填写地址和文字模型。在线服务需要 API Key；本机回环地址可留空。
3. 可主动获取模型、测试连接；也可直接填写实际模型 ID 后保存。普通 API 保存不以测试成功为门槛。
4. 点击编辑器底部「保存」。首个完整文字引擎可成为当前引擎；编辑已有引擎不会抢占正在使用的其他线路。

| 服务 | 协议 | 常见地址 |
| --- | --- | --- |
| OpenAI | OpenAI 兼容或 Responses | `https://api.openai.com/v1` |
| DeepSeek | OpenAI 兼容 | `https://api.deepseek.com` |
| Anthropic | Anthropic Messages | `https://api.anthropic.com` |
| Gemini | Gemini GenerateContent | `https://generativelanguage.googleapis.com` |
| Ollama | OpenAI 兼容 | `http://localhost:11434/v1` |
| LM Studio | OpenAI 兼容 | `http://localhost:1234/v1` |

模型 ID、账户权限与视觉能力以服务商的当前目录为准。自建网关使用自己的地址；不要把某个服务商的密钥填到另一地址。网络许可、局域网许可和 TLS 设置仍分别生效。

已保存的 API 引擎可以重新编辑地址、协议、模型与高级参数。修改连接参数后，旧目录和旧测试证据不再代表新配置；在旧地址上发起的模型查询不会写回新表单。

## 连接本机工具

1. 点击「连接本机工具」。检测只检查工具入口，不启动推理，也不把文件存在视为已登录。
2. 选择 oh-my-pi 或 Codex CLI，点击「连接 / 刷新账号」。这一步通过工具协议读取账号状态和模型。
3. 选择模型。OMP 如需新登录，可选择提供方并通过浏览器授权；必要时粘贴授权回调。
4. 可点击「测试翻译」，发送 `Hello world`，会使用所选模型的少量额度。
5. 「保存连接」只保存；「保存并使用」同时切换当前文字引擎。

- 本机 CLI 不等于本地推理：文字会发送到该工具配置的提供方并使用其额度；安全离线模式会阻止这条外发路线。
- 支持原生入口，以及可解析的官方包入口；不执行 `.cmd` / `.ps1` 脚本，不从当前目录猜测同名程序。
- 重新检测在后台执行，可取消。已保存但本次未发现的入口会保留并标明状态，不会被静默删除。
- 编辑、重新连接与重新保存沿用同一条引擎记录。若原模型不在当前目录中，需要明确重新选择，不会自动改用另一个模型。
- 「断开连接」禁用 PopGlot 的该连接并取消相关请求，保留工具自己的登录；之后可重新连接。

### 将 OMP 模型改为 API 直连

连接 OMP 并选择受支持提供方的模型后，展开「将所选模型改为 API 直连」。只有明确勾选授权后，才会导入所选提供方的普通 API Key 并存入 Windows 凭据管理器；不导入 OAuth 登录记录。多个有效 Key 不自动择一，可改为手工添加 API 引擎。

## ChatGPT 官方直连

在本机工具页展开「ChatGPT 官方直连（无需 CLI）」，选择「Continue with ChatGPT」。授权在官方浏览器页面完成；返回后刷新当前账号与工作区的模型目录，选择模型，再测试或保存并使用。

保存的模型名称只是回显，不代表账号目前仍有权限。刷新或切换账号会清掉旧测试证据。断开引擎与退出账号是不同操作：断开保留登录；退出会撤销该账号会话。可取消登录、模型刷新和测试等待；已经进入落盘提交阶段时不再显示可取消操作。

账号授权流程受官方服务与账号资格限制；隔离模拟验证不代表真实账号授权一定可用。

## 当前线路、图片和要点

- 文字引擎用于划词、工作台、查词和 OCR 识别后的文字翻译；视觉引擎负责获准上传的截图。
- 本地 OCR 只表示识别在本机完成，后续文字翻译是否联网取决于文字引擎。
- 安全离线模式、图片上传许可与实际截图路线可在「隐私与数据」查看；草稿会明确标为保存后生效。
- 公共翻译不支持自定义语气或整理要点。本机模型须配置自己的文字模型；在线模型还须满足当前联网许可和凭据要求。
- 切换引擎用于之后发起的请求；正在进行的翻译保留其请求快照，不会自动重发。

## 凭据与测试

API Key 按引擎存入 Windows Credential Manager，不写进普通配置或日志。未输入新 Key 不会覆盖已保存 Key。测试连接使用草稿和程序生成的短文本，不上传截图或历史；保存配置本身不联网。

模型推荐的极速、均衡、高质档位只提供建议。缺少能力证据时显示未知，不把模型名称猜测当成已验证能力。
