# 常见问题

## 没有可用的翻译引擎

在「设置 → 引擎」添加服务并选择文字模型，或在「隐私与数据」允许公共翻译，再从底部模型菜单选用。账号连接失败时，先连接或重新登录对应账号。

## 连接或翻译失败

| 提示 | 可以检查什么 |
| --- | --- |
| 401 / 403 | API Key 是否有效，账号是否过期或缺少所选模型权限；账号引擎可重新登录。 |
| 429 | 服务限流或额度不足。公共翻译通常冷却一分钟；其他服务按其提示等待，或手动换用其他引擎。 |
| 404 / 模型不可用 | 地址、协议和模型 ID 是否匹配，账号是否仍有权限。刷新模型列表后重新选择。 |
| 超时 / 连接失败 | 网络、代理、服务地址及提供方状态。已收到的文字仍会保留，可手动复制或重试。 |
| 网络未启用 / 安全离线模式 | 在「设置 → 隐私与数据」检查开关；也可选用本机模型。 |

「获取模型成功」只说明目录可读取，不代表翻译请求一定可用。修改账号、地址或模型后，需要重新测试；旧结果不能代表新配置。

## 截图识别不到文字

重新框选清晰的文字区域，或放大原界面后再截图。到「设置 → 隐私与数据 → 本机文字识别」查看可用语言。缺少语言包时，在 Windows 的语言选项中安装光学字符识别组件。

本地 OCR 不上传截图。使用视觉识别或图片直译，需要先配置视觉模型并允许上传截图。

## 快捷键没有反应

检查「设置 → 快捷键」中该动作是否已停用，或组合是否被其他程序占用。换一个组合后保存。管理员窗口里的选区可能无法通过模拟复制读取，可改用截图或将文字粘贴到主窗口。

工作台默认 Ctrl+Enter 翻译，Enter 换行；查词窗口按 Enter 翻译。输入本身不自动提交请求。

## 生词本或历史保存失败

先检查磁盘空间、目录权限和文件占用。读取失败时不要直接覆盖原文件；先备份 `%LOCALAPPDATA%\PopGlot` 中相应数据，再根据界面提示重试。损坏文件可能被另存为带时间戳的副本，便于恢复。

## 开机启动被 Windows 禁用

在任务管理器的「启动应用」中启用 PopGlot，再回到「设置 → 通用」查看状态。PopGlot 不会自行覆盖 Windows 对启动项的禁用决定。

## 反馈其他问题

在「设置 → 隐私与数据」点击「在浏览器中报告问题」，写明版本、操作步骤、预期结果和实际结果。需要附日志时，可从 `%LOCALAPPDATA%\PopGlot\logs` 获取 `crash-日期.log`，并在提交前检查内容。

自动崩溃诊断是另一个默认关闭的选项，需单独授权。详情见[隐私与数据](privacy-and-security.md)。
