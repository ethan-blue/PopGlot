# 隐私与数据

翻译由你主动发起，PopGlot 不持续监听剪贴板或屏幕。配置、翻译历史和生词本保存在本机。

## 哪些内容会联网

| 操作 | 发送内容与接收方 |
| --- | --- |
| 文字翻译、要点 | 原文及翻译指令，发给所选引擎。切换模型或风格后，有原文时会重新翻译。 |
| 本地 OCR | 截图在本机识别；随后翻译识别出的文字时，按所选引擎发送文字。 |
| 视觉识别、图片直译 | 获得图片上传许可后，截图发给所选视觉模型。 |
| 公共翻译 | 仅发送待译文本至选中的 Google（`translate.googleapis.com` / `clients5.google.com`）或 MyMemory（`api.mymemory.translated.net`），不发送截图、历史或密钥。 |
| 云端朗读 | 单独开启后，将待朗读文本发送给 Microsoft 在线语音服务；默认使用 Windows 本地语音。 |
| 获取模型、连接测试 | 访问所配置的服务；测试可能发送短示例并使用少量额度。 |
| 账号登录与续期 | 访问对应账号服务。Codex / OMP 登录由工具管理，ChatGPT 直连通过浏览器授权。 |
| 崩溃诊断上报 | 单独开启后，发送版本、系统信息与脱敏堆栈至 `api.github.com` 的项目 Issues。默认关闭。 |

API 密钥会随鉴权请求发送给配置的服务。填写中转或自建地址前，请确认你信任该接收方。本机 CLI 可能使用联网模型，安装在本机不代表推理在本机完成。

保存普通设置、切换页面或浏览历史不提交翻译。检测工具入口不等于连接账号或测试模型。

## 网络与上传开关

在「设置 → 隐私与数据」管理：

- 安全离线模式：阻止云端翻译、公共翻译、截图上传与云端朗读；本机回环地址的模型、本地 OCR 和本地数据仍可使用。
- 允许上传截图：用于视觉识别和图片直译。关闭后仍可使用本地 OCR，再翻译识别出的文字。
- 公共翻译：可允许、拒绝或恢复询问。「仅本次允许」只授权一次实际发送，不会变成永久许可。
- 云端朗读与崩溃诊断：各自单独授权，可随时撤销。

## 凭据

API Key 保存在 Windows 凭据管理器，目标名称为 `PopGlot/provider/<引擎 id>`，不写入普通配置文件。Codex / OMP 的账号凭据由对应工具保管，PopGlot 通过工具接口使用，不复制 OAuth token。

ChatGPT 直连授权独立保存在本机，由 Windows 加密保护。「断开引擎」与「退出账号」是不同操作，前者保留登录。

## 本地数据

默认目录为 `%LOCALAPPDATA%\PopGlot`。

| 数据 | 文件或位置 |
| --- | --- |
| 引擎列表 | `product-config.json` |
| 当前翻译设置 | `provider-settings.json` |
| 快捷键、主题与授权 | `windows-shell.json` |
| 自定义翻译风格 | `prompt-templates.json` |
| 翻译历史 | `history.json` |
| 生词本 | `vocabulary.json` |
| 诊断日志 | `diagnostics` 目录 |

历史最多保留 200 条、90 天、4 MiB。取消或未完成的翻译不入库。常见密钥、密码等特征会被过滤，这种规则检查不能识别所有敏感内容；处理敏感文本前可关闭历史记录。

截图只在内存中处理，不作为截图文件保存。历史和生词本文件是本地明文，请按需要保护 Windows 账号及备份。

## 问题反馈

「在浏览器中报告问题」不需要令牌，不会自动附加数据，由你检查后提交。

自动崩溃上报需要单独开启，并提供仅有目标仓库 Issues 写权限的 GitHub 令牌。令牌保存在 Windows 凭据管理器，可清除。诊断使用受限字段和脱敏处理，不收集翻译原文、译文或截图；分享本地日志前仍请自行检查内容。
