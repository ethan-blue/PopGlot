# 隐私边界与数据安全 (Privacy & Security)

PopGlot 将用户的数据所有权与隐私安全置于最高优先级。我们坚信工具软件应当边界清晰、行为可预期，绝不在后台暗中收集、窃取或滥用用户的私人信息。

---

## 核心安全原则

1. **本地优先 (Local-First)**：配置、历史记录、生词本与临时会话全部保存在用户本地磁盘；无需注册账号，没有远程同步服务器。
2. **零暗中出网 (Zero-Surprise Network)**：打开应用、启动托盘、切换设置、保存修改、浏览历史，一律绝不发起任何网络通信。
3. **显式动作触发**：只有当用户主动按下快捷键（划词/截图）或在输入框明确敲下 `Enter` 时，对应的内容片段才会按既定路由发送。
4. **凭据安全隔离**：API Key 绝不写入明文文本文件、普通配置文件或软件日志中。

---

## 什么数据会出网？

| 数据类型 | 是否出网 | 触发条件与目标去向 | 安全与脱敏防护 |
|---|:---:|---|---|
| **选中文本 / 输入正文** | **是** | 用户主动发起翻译，且「安全离线模式」处于关闭状态 | 仅发送给用户在「翻译引擎」中明确配置并设为默认的 Provider |
| **屏幕截图图片 (PNG)** | **默认否** | **本地 OCR 模式**：完全在本机 Windows OCR 引擎中离线解析，**绝不上传图片**<br>**视觉模型模式**：仅当用户显式配置视觉模型并在「隐私与数据」中打开图片上传授权时才发送 | 未授权时严格物理阻断图片上传，绝不悄悄降级外发 |
| **公共翻译文本** | **可选** | 用户未配置 API Key 且主动点击开启「内置公共翻译」 | 仅向 Google 公共翻译端点发送待翻译文本；不发截图、不发系统标识 |
| **语音朗读音频数据** | **默认否** | **本地语音**：默认使用 Windows SAPI / OneCore 离线语音合成，**绝不出网**<br>**云端朗读**：用户在「隐私与数据」显式开启云端朗读时，仅发送待朗读语句至在线语音服务 | 离线或未授权状态下强制使用本地语音 |
| **API Key / 密钥凭据** | **否** | 仅随翻译请求作为 HTTPS 鉴权请求头（Header）直接发送至目标服务商 | 不经过任何第三方中转代理，不进入任何日志 |

## 绝不出网的硬红线 (Hard Boundaries)

PopGlot 在代码层面构建了严格的出网门禁（`OutboundPolicy`）：

- **安全离线模式（一键切断）**：
  在「设置 → 隐私与数据」中开启「安全离线模式」后，应用将切断一切外部网络调用。无论是商业大模型、云端语音还是内置公共翻译，全部物理阻断。
- **保存配置零网络**：
  在「设置」窗口中修改快捷键、更改界面主题、编辑翻译引擎信息并保存时，完全在本地磁盘完成，绝不向外部发送探测包。
- **未填写 API Key 绝对不出网**：
  商业在线引擎（如 OpenAI、Claude 等）若未填写密钥，点击测试或翻译时在构建 HTTP 请求前就会被本地前置拦截，绝不向外发出无效的 401 报错包。
- **剪贴板安全瞬态还原**：
  划词翻译读取选区时通过 Windows 剪贴板事务处理，一旦读取完毕立即根据序列号还原用户先前的剪贴板内容，杜绝剪贴板被持久占用。

## 内置公共翻译的授权语义

为了保障开箱即用，PopGlot 提供了内置免费公共翻译作为后备线路：
1. **明确接收方披露**：首次使用前，系统会明确弹窗提示：「内置公共翻译把待翻译文字发送到 translate.googleapis.com 与 clients5.google.com；不发送截图、历史记录或密钥」；
2. **独立撤销权**：授权状态记录在本地 `windows-shell.json` 的 `FreeEngineConsent` 字段中，用户可随时在「设置 → 隐私与数据」中撤销授权；
3. **撤销即失效**：一旦撤销，所有公共翻译请求立即中止，未配置其他可用引擎时将安全引导至设置页。

## 本地数据存储规范

### 1. API Key 安全保险箱
- 用户的 API Key 统一托管在操作系统的 **Windows Credential Manager（Windows 凭据管理器）** 中；
- 存储目标格式为 `PopGlot/Profile/{ProfileId}`，受到 Windows 用户账户级别（DPAPI）的强加密保护；
- 导出的调试日志、崩溃堆栈或普通配置文件中绝不含有任何密钥字符。

### 2. 翻译历史管理 (`history.json`)
- **存储路径**：`%LOCALAPPDATA%\PopGlot\history.json`；
- **容量与周期上限**：最多存储 **200 条** 历史记录，最多保留 **90 天**，文件大小物理硬上限为 **4 MiB**；
- **敏感信息自动过滤**：
  - 系统内置正则过滤器，疑似 API Key、私钥、密码或高危 Token 的文本**绝不写入历史记录**；
  - 超过 4,000 字符的原文或超过 8,000 字符的译文自动拒绝入库；
  - 截图的位图图像（PNG/BMP）绝不入库，仅存储最终识别出的文字；
- **用户自决管理**：用户可在「资料库」中随时搜索、单条删除历史，或在「设置 → 隐私与数据」中一键永久清空全部历史。

### 3. 生词本持久化 (`vocabulary.json`)
- **存储路径**：`%LOCALAPPDATA%\PopGlot\vocabulary.json`；
- **后台异步安全写入**：收藏与取消收藏操作在内存中即时生效，后台通过单写者安全队列串行落盘，杜绝 UI 界面卡顿；
- **损坏只读防破坏（C02 合同）**：若生词本文件在系统意外断电时出现格式异常，PopGlot 会将其隔离并置为只读保护状态，绝不以空文件覆盖破坏用户的已有资产。

## 诊断日志与去标识化 (Anonymized Diagnostics)

为了在发生程序故障时能够准确定位问题，PopGlot 维护本地诊断日志文件：
- **记录内容**：仅记录请求唯一 UUID、Provider 协议类型、HTTP 响应状态码、网络耗时毫秒数与异常类型名（例如 `HttpRequestException`）；
- **绝不记录内容**：
  - 严禁记录用户输入的待翻译原文；
  - 严禁记录大模型输出的译文正文；
  - 严禁记录 API Key、Authorization 请求头或认证令牌；
  - 严禁记录截图内容或内存位图；
- 诊断日志滚动保留，体积受严格上限约束，绝不上载至云端。
