# 隐私边界与数据安全 (Privacy & Security)

配置、历史与生词本保存在本机。翻译、连接测试、模型刷新和账号授权由用户主动触发；接收方取决于所选引擎。

---

## 核心安全原则

1. **本地优先 (Local-First)**：配置、历史记录、生词本与临时会话全部保存在用户本地磁盘；无需注册账号，没有远程同步服务器。
2. **保存不联网**：启动托盘、保存设置、切换页面、浏览历史不会主动发出模型请求。
3. **显式联网动作**：翻译、测试连接、获取模型、账号登录与云端朗读会按对应许可访问所选服务。
4. **凭据安全隔离**：API Key 绝不写入明文文本文件、普通配置文件或软件日志中。

---

## 什么数据会出网？

| 数据类型 | 是否出网 | 触发条件与目标去向 | 安全与脱敏防护 |
|---|:---:|---|---|
| **选中文本 / 输入正文** | **是** | 用户主动发起翻译，且「安全离线模式」处于关闭状态 | 仅发送给用户在「翻译引擎」中明确配置并设为默认的 Provider |
| **屏幕截图图片 (PNG)** | **默认否** | **本地 OCR 模式**：完全在本机 Windows OCR 引擎中离线解析，**绝不上传图片**<br>**视觉模型模式**：仅当用户显式配置视觉模型并在「隐私与数据」中打开图片上传授权时才发送 | 未授权时严格物理阻断图片上传，绝不悄悄降级外发 |
| **公共翻译文本** | **可选** | 用户未配置 API Key 且主动点击开启「内置公共翻译」 | 仅向选中的公共端点（Google: `translate.googleapis.com` / `clients5.google.com` 或 MyMemory: `api.mymemory.translated.net`）发送待翻译文本；不发截图、不发系统标识或凭据 |
| **语音朗读音频数据** | **默认否** | **本地语音**：默认使用 Windows SAPI / OneCore 离线语音合成，**绝不出网**<br>**云端朗读**：用户在「隐私与数据」显式开启云端朗读时，仅发送待朗读语句至在线语音服务 | 离线或未授权状态下强制使用本地语音 |
| **API Key / 密钥凭据** | **鉴权时发送** | 用户调用所配置的服务时，随 HTTPS 鉴权请求头直接发送至该服务商 | 不写入普通配置、翻译历史或日志 |
| **崩溃诊断报告** | **默认否（可选）** | 用户在「设置 → 隐私与数据」显式开启「GitHub 问题上报」并粘贴 GitHub 访问令牌后：程序遇到严重崩溃时，向 `api.github.com`（ethan-blue/PopGlot 仓库 Issues）发送一份脱敏诊断；也可点击「发送测试诊断」主动连通性验证 | 仅含版本、操作系统、.NET 运行时与已脱敏的崩溃类型/堆栈；不含翻译文本、截图、带查询串的地址或凭据；正文硬上限 24,000 字符，发送前再过一遍脱敏电池 |

## 绝不出网的硬红线 (Hard Boundaries)

PopGlot 在代码层面构建了严格的出网门禁（`OutboundPolicy`）：

- **安全离线模式（一键切断）**：
  在「设置 → 隐私与数据」中开启并保存「安全离线模式」后，云端模型、云端语音与公共翻译均被阻止；本机回环地址的模型和本地 OCR 仍可使用。本机 CLI 不等于本地推理，其联网模型同样受此开关约束。
- **保存配置零网络**：
  在「设置」窗口中修改快捷键、更改界面主题、编辑翻译引擎信息并保存时，完全在本地磁盘完成，绝不向外部发送探测包。
- **未填写 API Key 绝对不出网**：
  商业在线引擎（如 OpenAI、Claude 等）若未填写密钥，点击测试或翻译时在构建 HTTP 请求前就会被本地前置拦截，绝不向外发出无效的 401 报错包。
- **剪贴板安全瞬态还原**：
  划词翻译读取选区时通过 Windows 剪贴板事务处理，一旦读取完毕立即根据序列号还原用户先前的剪贴板内容，杜绝剪贴板被持久占用。

## 内置公共翻译的授权语义

为了保障开箱即用，PopGlot 提供了内置免费公共翻译作为后备线路：
1. **明确接收方披露**：免费引擎有两条可选线路，一次只使用选中的那一条。Google 线路发往 `translate.googleapis.com` 与 `clients5.google.com`；备用线路发往 `api.mymemory.translated.net`。两者都只发送待翻译文字，不发送截图、历史记录或密钥。
2. **独立撤销权**：授权状态记录在本地 `windows-shell.json` 的 `FreeEngineConsent` 字段中，用户可随时在「设置 → 隐私与数据」中撤销授权；
3. **撤销即失效**：一旦撤销，所有公共翻译请求立即中止，未配置其他可用引擎时将安全引导至设置页。

## GitHub 问题上报（自我迭代）

为了让崩溃能被开发者直接看到并修复，PopGlot 提供完全可选的 GitHub Issue 诊断上报：

1. **默认关闭**：该功能默认不开启；只有你在「设置 → 隐私与数据 → GitHub 问题上报」主动勾选同意后才会上传，升级也绝不会隐式替你打开。
2. **令牌只由你提供**：上传需要一个你自己创建并粘贴的 GitHub Personal Access Token（需 Issues 写权限）。它只保存在本机 **Windows 凭据管理器**（目标 `PopGlot/telemetry/github`），不写入配置文件、翻译历史或日志；可随时点击「清除令牌」删除。
3. **只送脱敏诊断与版本**：报告仅包含程序版本、构建标识、操作系统、.NET 运行时，以及本地诊断日志中已脱敏的崩溃类型与堆栈（类型名、阶段、HResult、事件 ID、方法名）。**绝不包含**翻译原文与译文、截图、带查询串的地址或任何凭据；发送前还会再做一次令牌/密钥形状扫描，正文硬上限 24,000 字符。
4. **随时撤销**：取消勾选同意开关即立即撤销——之后即使发生崩溃也不会再向 GitHub 上传任何内容。

## 本地数据存储规范

### 1. API Key 安全保险箱
- 用户的 API Key 统一托管在操作系统的 **Windows Credential Manager（Windows 凭据管理器）** 中；
- 存储目标格式为 `PopGlot/provider/{id}`（兼容读取早期版本的 `PopGlot/Profile/{ProfileId}`），由 Windows 凭据管理器安全保存，使用当前登录用户的 Windows 数据保护 API（DPAPI）加密保护；
- 导出的调试日志、崩溃堆栈或普通配置文件中绝不含有任何密钥字符。

### 2. 翻译历史管理 (`history.json`)
- **存储路径**：`%LOCALAPPDATA%\PopGlot\history.json`；
- **容量与周期上限**：最多存储 **200 条** 历史记录，最多保留 **90 天**，文件大小物理硬上限为 **4 MiB**；
- **敏感信息自动过滤（启发式防护）**：
  - 系统检查原文、译文、补充说明与保留术语，命中以下特征时**拒绝写入历史记录**：
    - 私钥标头（如 `-----BEGIN ... PRIVATE KEY-----`）；
    - 常见密码模式（如 `password:`、`password=`）；
    - 常见 API Key 与 Secret 键值对（如 `api_key:`、`secret=`）；
    - 常见知名服务商 Token 前缀及长度（如 OpenAI `sk-...`、Google `AIza...`、GitHub `ghp_...` 等）；
  - 超过 4,000 字符的原文或超过 8,000 字符的译文自动拒绝入库；
  - 截图的位图图像（PNG/BMP）绝不入库，仅存储最终识别出的文字；
  - **边界说明**：此过滤为客户端轻量启发式拦截，并非全能 DLP（数据防泄漏）系统，无法识别任意形态的商业秘密或未命中模式的敏感内容。**在处理高度敏感、涉密或合规要求极高的业务场景时，强烈建议在「设置 → 隐私与数据」中直接关闭「记录翻译历史」**。
  - 重新读取历史时也过滤无效字段与命中上述规则的条目，避免旧记录在搜索、预览或导出时绕过检查。
- **用户自决管理**：用户可在「资料库」中随时搜索、单条删除历史，或在「设置 → 隐私与数据」中一键永久清空全部历史。

### 3. 生词本持久化 (`vocabulary.json`)
- **存储路径**：`%LOCALAPPDATA%\PopGlot\vocabulary.json`；
- **后台异步安全写入**：收藏与取消收藏操作在内存中即时生效，后台通过单写者安全队列串行落盘，杜绝 UI 界面卡顿；
- **损坏只读防破坏（C02 合同）**：若生词本文件在系统意外断电时出现格式异常，PopGlot 会将其隔离并置为只读保护状态，绝不以空文件覆盖破坏用户的已有资产。

## 诊断日志与去标识化 (Anonymized Diagnostics)

为了在发生程序故障时能够准确定位问题，PopGlot 维护本地诊断日志文件：
- **记录内容**：仅记录请求唯一 UUID、Provider 协议类型、HTTP 响应状态码、网络耗时毫秒数与异常类型名（例如 `HttpRequestException`）；
- **绝不记录内容**：
  - 严禁记录用户输入的待翻译原文；
  - 严禁记录大模型输出的译文正文；
  - 严禁记录 API Key、Authorization 请求头或认证令牌；
  - 严禁记录截图内容或内存位图；
- 诊断日志滚动保留，体积受严格上限约束，绝不上载至云端。
