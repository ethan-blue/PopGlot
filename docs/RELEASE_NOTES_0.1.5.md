# PopGlot 0.1.5 发布说明

0.1.5 是稳定性与界面修复版本，重点解决窗口卡顿、重复副作用、首次添加引擎入口不可点击、设置页重复路由，以及小尺寸图标不清晰的问题。

## 主要变化

- 首次使用时的「添加第一个引擎」现在使用真实可命中的按钮，点击后直接进入新增引擎流程。
- 设置页移除重复路由选择；翻译引擎切换统一保留在主窗口底部。
- 历史、词库、日志、服务配置和启动项操作减少 UI 线程同步 I/O。
- 流式翻译、取消、自动复制、历史提交和异常恢复使用更严格的单次提交边界。
- 改进窄窗口、多显示器 DPI、主题、高对比、浮窗定位和控件状态。
- 使用新的 v5 扁平双气泡图标，并针对 16–256px Windows 图标尺寸生成独立图层。

## 下载

下载 `PopGlot-v0.1.5-win-x64.zip` 及同名 `.sha256` 文件。该包为 Windows 10 19041+ / Windows 11 x64 自包含便携版，无需预装 .NET。

```powershell
(Get-FileHash -Path .\PopGlot-v0.1.5-win-x64.zip -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\PopGlot-v0.1.5-win-x64.zip.sha256
```
